Unit 1

Limits & Continuity

The bedrock of calculus. Understanding what a function approaches — even if it never arrives — unlocks everything that follows.

What is a Limit?

The limit describes what value \(f(x)\) approaches as \(x\) approaches some value \(c\), regardless of whether \(f(c)\) is even defined. This is the core idea that separates calculus from algebra.

Informal Definition
\(\displaystyle\lim_{x \to c} f(x) = L\) means: we can make \(f(x)\) as close to \(L\) as we want by choosing \(x\) close enough (but not equal) to \(c\).
Formal ε–δ Definition
For every \(\varepsilon > 0\), there exists \(\delta > 0\) such that: $$0 < |x - c| < \delta \implies |f(x) - L| < \varepsilon$$ The \(0 <\) part is crucial: \(x \neq c\). The limit doesn't care about the value at \(c\).
Graph: Limit Exists Even With a Hole

\(\lim_{x\to 2}\dfrac{x^2-4}{x-2} = 4\) — limit is 4 even though \(f(2)\) is undefined (open circle)

Limit Laws
Sum / Difference
\(\lim[f \pm g] = \lim f \pm \lim g\)
Product
\(\lim[f \cdot g] = \lim f \cdot \lim g\)
Quotient
\(\displaystyle\lim\frac{f}{g} = \frac{\lim f}{\lim g}\), \quad \lim g \neq 0\)
Power Rule
\(\lim [f(x)]^n = [\lim f(x)]^n\)
One-Sided Limits
Two-sided limit exists if and only if both one-sided limits agree $$\lim_{x \to c} f(x) = L \iff \lim_{x \to c^-} f(x) = \lim_{x \to c^+} f(x) = L$$
Jump Discontinuity — one-sided limits differ
One-sided limits equal — limit exists
Limits at Infinity
Rational: degree comparison
\(\deg \text{num} < \deg \text{den}\): → \(0\)
\(\deg \text{num} = \deg \text{den}\): → lead coeff ratio
\(\deg \text{num} > \deg \text{den}\): → \(\pm\infty\)
Growth Hierarchy
\(\ln n \ll n^p \ll a^n \ll n! \ll n^n\)
As \(n \to \infty\). Use this to evaluate limits by dominant term.
Essential Limits — Memorize All
Trig #1 ★ KEY
\(\displaystyle\lim_{x \to 0} \frac{\sin x}{x} = 1\)
Trig #2 ★ KEY
\(\displaystyle\lim_{x \to 0} \frac{1 - \cos x}{x} = 0\)
Natural Base
\(\displaystyle\lim_{n \to \infty}\!\left(1 + \tfrac{1}{n}\right)^n = e\)
General e-form
\(\displaystyle\lim_{x \to 0}(1+x)^{1/x} = e\)
Exponential
\(\displaystyle\lim_{x \to 0} \frac{e^x - 1}{x} = 1\)
Logarithm
\(\displaystyle\lim_{x \to 0} \frac{\ln(1+x)}{x} = 1\)
Visual Proof: sin(x)/x → 1 as x → 0

The function \(\frac{\sin x}{x}\) approaches 1 from both sides even though it's undefined at \(x = 0\)

Generalizing the Trig Limits
General Pattern
\(\displaystyle\lim_{x \to 0}\frac{\sin(ax)}{bx} = \frac{a}{b}\)
Multiply and divide to match the pattern: \(\frac{\sin(ax)}{ax} \to 1\)
Example
\(\displaystyle\lim_{x \to 0}\frac{\sin(5x)}{3x} = \frac{5}{3}\)
\(= \dfrac{5}{3} \cdot \underbrace{\dfrac{\sin(5x)}{5x}}_{\to 1} \to \dfrac{5}{3}\)
Any limit involving \(\sin\) or \(\cos\) that gives \(0/0\) can often be solved using these special limits OR L'Hôpital's Rule (Unit 4).
Definition of Continuity
Three Conditions for Continuity at \(x = c\)
1. \(f(c)\) is defined
2. \(\displaystyle\lim_{x \to c} f(x)\) exists
3. \(\displaystyle\lim_{x \to c} f(x) = f(c)\)
Violating even one condition creates a discontinuity. Most AP problems test whether you identify WHICH condition fails.
Types of Discontinuities
Removable (Hole)

Limit exists but ≠ f(c). "Fixable" by redefining f(c).

Jump

Left and right limits exist but differ.

Infinite (Asymptote)

Limit is ±∞. Vertical asymptote.

Continuity on an Interval

A function is continuous on \([a,b]\) if it is continuous at every point in the interval, including one-sided continuity at the endpoints. Polynomials, trig, exponential, and logarithmic functions are all continuous on their domains.

Intermediate Value Theorem (IVT)
If \(f\) is continuous on \([a, b]\) and \(M\) is any number between \(f(a)\) and \(f(b)\), then there exists at least one \(c \in (a, b)\) with \(f(c) = M\).

Key use: Prove a root exists — if \(f(a) < 0\) and \(f(b) > 0\), a zero must exist in \((a,b)\).
IVT — The function must cross every value between f(a) and f(b)
IVT guarantees existence, not uniqueness. Always verify continuity FIRST. IVT cannot find the exact value of \(c\).
Squeeze Theorem
If \(g(x) \le f(x) \le h(x)\) near \(x = c\), and
\(\displaystyle\lim_{x \to c} g(x) = \lim_{x \to c} h(x) = L\),
then \(\displaystyle\lim_{x \to c} f(x) = L\).
Squeeze Theorem: bounding x²sin(1/x)

\(-x^2 \le x^2\sin(1/x) \le x^2\), both bounds → 0, so the middle function → 0

Practice Problems
MC\(\displaystyle\lim_{x \to 3} \frac{x^2 - 9}{x - 3}\) = ?
Solution
1
Direct substitution gives \(\frac{9-9}{3-3} = \frac{0}{0}\) — indeterminate form.
2
Factor: \(\frac{x^2-9}{x-3} = \frac{(x-3)(x+3)}{x-3}\)
3
Cancel \((x-3)\) (valid since limit doesn't require \(x = 3\)): \(\frac{(x+3)\cancel{(x-3)}}{\cancel{(x-3)}} = x + 3\)
4
Now substitute: \(\lim_{x\to 3}(x+3) = 6\)
Answer
\(\displaystyle\lim_{x \to 3} \frac{x^2-9}{x-3} = 6\)
MCDoes \(\displaystyle\lim_{x \to 0} \frac{|x|}{x}\) exist?
Solution
1
Check left-hand limit: as \(x \to 0^-\), \(|x| = -x\), so \(\frac{|x|}{x} = \frac{-x}{x} = -1\)
2
Check right-hand limit: as \(x \to 0^+\), \(|x| = x\), so \(\frac{|x|}{x} = \frac{x}{x} = 1\)
3
Since \(\lim_{x\to 0^-} = -1 \neq 1 = \lim_{x\to 0^+}\), the two-sided limit does NOT exist.
Answer
The limit does NOT exist (DNE) — jump discontinuity at \(x = 0\).
FRQShow that \(f(x) = x^3 - 2x - 5\) has a root on \([2, 3]\).
Solution — using IVT
1
\(f(x) = x^3 - 2x - 5\) is a polynomial, so it is continuous everywhere, including on \([2, 3]\).
2
Evaluate endpoints: \(f(2) = 8 - 4 - 5 = -1 < 0\) and \(f(3) = 27 - 6 - 5 = 16 > 0\)
3
Since \(f(2) < 0 < f(3)\) and \(f\) is continuous on \([2,3]\), by the Intermediate Value Theorem, there exists at least one \(c \in (2, 3)\) such that \(f(c) = 0\). ∎
Key Phrase for FRQ
State: (1) continuity, (2) signs of endpoints, (3) cite IVT by name.
HARDFind \(\displaystyle\lim_{x \to 0} x^2 \sin\!\left(\frac{1}{x}\right)\)
Solution — Squeeze Theorem
1
Note that \(-1 \le \sin\!\left(\frac{1}{x}\right) \le 1\) for all \(x \neq 0\).
2
Multiply through by \(x^2 \ge 0\): \(-x^2 \le x^2 \sin\!\left(\frac{1}{x}\right) \le x^2\)
3
\(\lim_{x\to 0}(-x^2) = 0\) and \(\lim_{x\to 0} x^2 = 0\)
4
By the Squeeze Theorem: \(\lim_{x\to 0} x^2 \sin(1/x) = 0\)
Answer
\(0\). Cannot use algebra here — must squeeze!
Unit 2

Basic Differentiation

The derivative as a limit, all core rules, and the complete table of derivatives for every function type you'll encounter.

Definition of the Derivative
Limit Definition
\(\displaystyle f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}\)
Alternate Form
\(\displaystyle f'(a) = \lim_{x \to a} \frac{f(x)-f(a)}{x-a}\)
The derivative as the limit of secant slopes → tangent slope

As \(h \to 0\), the secant line (blue) approaches the tangent line (gold) at \(x = 1\)

Differentiability → Continuity
If \(f\) is differentiable at \(x = c\), then \(f\) is continuous at \(c\).
The converse is FALSE. Continuous does NOT imply differentiable.
Fails at: corners, cusps, vertical tangents, jumps.
Not Differentiable: Corner at x = 0
Not Differentiable: Vertical Tangent
Core Differentiation Rules
Constant
\(\dfrac{d}{dx}[c] = 0\)
Power Rule ★ Most Used
\(\dfrac{d}{dx}[x^n] = nx^{n-1}\)
Works for all real \(n\): \(\frac{d}{dx}[x^{1/2}] = \frac{1}{2}x^{-1/2}\), \(\frac{d}{dx}[x^{-3}] = -3x^{-4}\)
Constant Multiple
\(\dfrac{d}{dx}[cf(x)] = c \cdot f'(x)\)
Sum / Difference
\(\dfrac{d}{dx}[f \pm g] = f' \pm g'\)
Product & Quotient Rules
Product Rule ★
\(\dfrac{d}{dx}[u \cdot v] = u'v + uv'\)
"First d-Second + Second d-First"
Example: \(\frac{d}{dx}[x^2 \sin x] = 2x\sin x + x^2\cos x\)
Quotient Rule ★
\(\dfrac{d}{dx}\!\left[\dfrac{u}{v}\right] = \dfrac{u'v - uv'}{v^2}\)
"Low dHigh − High dLow over Low²"
Example: \(\frac{d}{dx}\!\left[\frac{x^2}{e^x}\right] = \frac{2xe^x - x^2e^x}{e^{2x}} = \frac{x(2-x)}{e^x}\)
Quotient Rule numerator is \(u'v - uv'\), NOT \(uv' - u'v\). The TOP function's derivative comes first in the numerator.
Trig Derivatives
f(x)f'(x)Memory Hook
\(\sin x\)\(\cos x\)
\(\cos x\)\(-\sin x\)Negative sign!
\(\tan x\)\(\sec^2 x\)"tan → sec squared"
\(\cot x\)\(-\csc^2 x\)Negative, "cot → csc squared"
\(\sec x\)\(\sec x \tan x\)"sec tan"
\(\csc x\)\(-\csc x \cot x\)Negative, "csc cot"
The three "co" functions (cos, cot, csc) always have a negative sign in their derivatives. Easy pattern.
Exponential & Log Derivatives
\(e^x\) — unique!
\(\dfrac{d}{dx}[e^x] = e^x\)
The ONLY function that is its own derivative.
General exponential
\(\dfrac{d}{dx}[a^x] = a^x \ln a\)
Natural log
\(\dfrac{d}{dx}[\ln x] = \dfrac{1}{x},\quad x > 0\)
General log
\(\dfrac{d}{dx}[\log_a x] = \dfrac{1}{x \ln a}\)
|x| version
\(\dfrac{d}{dx}[\ln|x|] = \dfrac{1}{x},\quad x \neq 0\)
Tangent & Normal Lines
Tangent Line at \((a, f(a))\)
\(y - f(a) = f'(a)(x - a)\)
Slope = \(f'(a)\). Use point-slope form.
Normal Line at \((a, f(a))\)
\(y - f(a) = -\dfrac{1}{f'(a)}(x - a)\)
Perpendicular to tangent. Slope is negative reciprocal of \(f'(a)\).
Tangent and Normal Lines to f(x) = x² at x = 1
Higher Order Derivatives
Notation
\(f', f'', f''', f^{(4)}, \ldots, f^{(n)}\)
\(\dfrac{dy}{dx},\ \dfrac{d^2y}{dx^2},\ \dfrac{d^3y}{dx^3}\)
Cycling Derivatives of sin/cos
\(\sin x \to \cos x \to -\sin x \to -\cos x \to \sin x\)
Cycle length: 4
Practice Problems
MCFind \(f'(x)\) for \(f(x) = 3x^4 - \sqrt{x} + \dfrac{2}{x^3}\)
Solution — Rewrite, then Power Rule
1
Rewrite as: \(f(x) = 3x^4 - x^{1/2} + 2x^{-3}\)
2
Apply power rule term by term: \(f'(x) = 12x^3 - \frac{1}{2}x^{-1/2} + (-6)x^{-4}\)
3
Clean up: \(f'(x) = 12x^3 - \dfrac{1}{2\sqrt{x}} - \dfrac{6}{x^4}\)
Answer
\(f'(x) = 12x^3 - \dfrac{1}{2\sqrt{x}} - \dfrac{6}{x^4}\)
MCFind the equation of the tangent line to \(y = x^3 - 2x\) at \(x = 2\).
Solution
1
Find the point: \(y(2) = 8 - 4 = 4\) → point \((2, 4)\)
2
Find the slope: \(y' = 3x^2 - 2\), so \(y'(2) = 12 - 2 = 10\)
3
Point-slope form: \(y - 4 = 10(x - 2)\) → \(y = 10x - 16\)
Answer
\(y = 10x - 16\)
HARDUsing the limit definition, find \(f'(x)\) for \(f(x) = \sqrt{x}\).
Solution — Limit Definition + Conjugate
1
\(f'(x) = \displaystyle\lim_{h \to 0} \frac{\sqrt{x+h} - \sqrt{x}}{h}\)
2
Multiply by conjugate: \(\cdot\dfrac{\sqrt{x+h}+\sqrt{x}}{\sqrt{x+h}+\sqrt{x}}\) → numerator becomes \((x+h) - x = h\)
3
\(= \displaystyle\lim_{h \to 0} \frac{h}{h(\sqrt{x+h}+\sqrt{x})} = \lim_{h\to 0} \frac{1}{\sqrt{x+h}+\sqrt{x}} = \frac{1}{2\sqrt{x}}\)
Answer
\(f'(x) = \dfrac{1}{2\sqrt{x}}\) — confirms the power rule: \(\frac{d}{dx}[x^{1/2}] = \frac{1}{2}x^{-1/2}\)
Unit 3

Advanced Differentiation

Chain rule, implicit differentiation, inverse function derivatives, and all six inverse trig derivatives.

The Chain Rule
Composite Function Derivative$$\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$$
"Peel the onion" — differentiate the outermost function first, leaving the inside unchanged, then multiply by the derivative of the inside.
Leibniz Form
\(\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}\)
Chain + Power
\(\dfrac{d}{dx}[u^n] = nu^{n-1} \cdot u'\)
Chain + Trig
\(\dfrac{d}{dx}[\sin u] = \cos u \cdot u'\)
Chain + Exp
\(\dfrac{d}{dx}[e^u] = e^u \cdot u'\)
Chain + Log
\(\dfrac{d}{dx}[\ln u] = \dfrac{u'}{u}\)
General base
\(\dfrac{d}{dx}[a^u] = a^u \ln a \cdot u'\)
The #1 chain rule mistake: \(\dfrac{d}{dx}[\sin(x^2)] \neq \cos(x^2)\). You must multiply by \(2x\): the answer is \(\cos(x^2) \cdot 2x\).
Chain Rule: Nested composition — each layer adds a factor

\(f(x) = \sin(x^2)\) vs \(f'(x) = 2x\cos(x^2)\) — notice how \(f'\) oscillates faster and grows in amplitude

Implicit Differentiation

Used when \(y\) can't be solved explicitly in terms of \(x\), or when it's easier not to. Differentiate both sides with respect to \(x\), treating \(y\) as a function of \(x\).

Differentiate every term with respect to \(x\). Any term with \(y\) gains a factor \(\frac{dy}{dx}\).
Collect all terms containing \(\frac{dy}{dx}\) on one side.
Factor out \(\frac{dy}{dx}\) and divide to isolate it.
Key Pattern
\(\dfrac{d}{dx}[y^n] = ny^{n-1} \cdot \dfrac{dy}{dx}\)
Example: \(\frac{d}{dx}[x^2 + y^2] = 2x + 2y\frac{dy}{dx} = 0 \implies \frac{dy}{dx} = -\frac{x}{y}\)
Implicit curve: x² + y² = 25 (circle) — tangent line at (3, 4)

\(\frac{dy}{dx} = -\frac{x}{y} = -\frac{3}{4}\) at \((3, 4)\)

Inverse Function Derivative Theorem
Inverse Function Derivative
If \(f\) and \(f^{-1}\) are inverse functions: $$(f^{-1})'(b) = \frac{1}{f'(f^{-1}(b))} = \frac{1}{f'(a)} \text{ where } f(a) = b$$ Equivalently: \(\dfrac{dx}{dy} = \dfrac{1}{dy/dx}\)
Classic AP format: "Given \(f(3) = 7\) and \(f'(3) = 4\), find \((f^{-1})'(7)\)." Since \(f(3)=7\), we know \(f^{-1}(7)=3\). So \((f^{-1})'(7) = 1/f'(3) = 1/4\).
Inverse Trig Derivatives
f(x)f'(x)Domain
\(\arcsin x\)\(\dfrac{1}{\sqrt{1-x^2}}\)\(|x| < 1\)
\(\arccos x\)\(-\dfrac{1}{\sqrt{1-x^2}}\)\(|x| < 1\)
\(\arctan x\)\(\dfrac{1}{1+x^2}\)all \(x\)
\(\text{arccot}\, x\)\(-\dfrac{1}{1+x^2}\)all \(x\)
\(\text{arcsec}\, x\)\(\dfrac{1}{|x|\sqrt{x^2-1}}\)\(|x| > 1\)
\(\text{arccsc}\, x\)\(-\dfrac{1}{|x|\sqrt{x^2-1}}\)\(|x| > 1\)
All "co" versions (arccos, arccot, arccsc) have a negative sign. With chain rule: \(\frac{d}{dx}[\arctan(u)] = \frac{u'}{1+u^2}\). Apply this pattern to all six.
Logarithmic Differentiation

Use when differentiating products/quotients of many functions, or variable-base exponentials like \(x^{\sin x}\) or \((2x)^x\).

Take \(\ln\) of both sides: \(\ln y = \ln[f(x)]\)
Simplify using log properties: \(\ln(ab) = \ln a + \ln b\), \(\ln(a^n) = n\ln a\)
Differentiate implicitly: \(\dfrac{1}{y}\cdot y' = [\cdots]\)
Multiply both sides by \(y\), then back-substitute \(y = f(x)\)
Classic: \(y = x^x\)
\(\ln y = x\ln x\)
\(\frac{y'}{y} = \ln x + 1\)
\(y' = x^x(\ln x + 1)\)
General: \(y = [f(x)]^{g(x)}\)
\(\ln y = g(x)\ln f(x)\)
Differentiate right side with product rule
Practice Problems
MCDifferentiate \(f(x) = e^{\sin(x^2)}\)
Triple Chain Rule — 3 layers
1
Layer 1 (outermost): \(\frac{d}{dx}[e^u] = e^u \cdot u'\) where \(u = \sin(x^2)\)
2
Layer 2: \(\frac{d}{dx}[\sin(v)] = \cos(v) \cdot v'\) where \(v = x^2\)
3
Layer 3: \(\frac{d}{dx}[x^2] = 2x\)
4
Combine: \(f'(x) = e^{\sin(x^2)} \cdot \cos(x^2) \cdot 2x\)
Answer
\(f'(x) = 2xe^{\sin(x^2)}\cos(x^2)\)
FRQFind \(\dfrac{dy}{dx}\) for \(x^3 + xy^2 = 8\) at the point \((2, 0)\).
Implicit Differentiation
1
Differentiate both sides: \(3x^2 + [y^2 + x \cdot 2y\frac{dy}{dx}] = 0\)
2
Solve for \(\frac{dy}{dx}\): \(2xy\frac{dy}{dx} = -3x^2 - y^2\) → \(\frac{dy}{dx} = \frac{-3x^2 - y^2}{2xy}\)
3
Substitute \((2, 0)\): \(\frac{dy}{dx} = \frac{-3(4) - 0}{2(2)(0)} = \frac{-12}{0}\) → undefined!
4
Undefined slope means the tangent is vertical at \((2, 0)\).
Answer
Vertical tangent at \((2, 0)\) — \(\frac{dy}{dx}\) is undefined (DNE).

Motion problems, related rates, linearization, and L'Hôpital's Rule.

Motion Along a Line
Position
\(s(t)\)
Velocity
\(v(t) = s'(t)\)
Acceleration
\(a(t) = v'(t) = s''(t)\)
Speed
\(|v(t)| \ge 0\) always
Speeding Up
\(v(t)\) and \(a(t)\) same sign
Slowing Down
\(v(t)\) and \(a(t)\) opposite signs
Particle changes direction when \(v(t) = 0\) AND \(v(t)\) changes sign. Zeros without sign change are NOT direction changes.
Position, Velocity, and Acceleration for s(t) = t³ − 6t² + 9t

Gold = position, Blue = velocity, Green = acceleration. Particle changes direction at t = 1 and t = 3.

Related Rates

All variables change with time. Differentiate an equation relating them implicitly with respect to \(t\).

Draw a diagram. Label every quantity that changes as a variable.
Write an equation relating the variables.
Differentiate both sides w.r.t. \(t\). Every variable gets a rate \(\frac{d(\cdot)}{dt}\).
Substitute known values (AFTER differentiating!) and solve.
Never substitute values before differentiating. You'll treat a changing quantity as a constant and get the wrong answer.
Circle
\(A = \pi r^2 \Rightarrow \dfrac{dA}{dt} = 2\pi r \cdot \dfrac{dr}{dt}\)
Sphere
\(V = \tfrac{4}{3}\pi r^3 \Rightarrow \dfrac{dV}{dt} = 4\pi r^2 \dfrac{dr}{dt}\)
Pythagorean
\(a^2 + b^2 = c^2\)
\(2a\dot{a} + 2b\dot{b} = 2c\dot{c}\)
Cone Volume
\(V = \tfrac{1}{3}\pi r^2 h\)
Use similar triangles to eliminate \(r\)
Linearization & Differentials
Linear Approximation (Tangent Line Approximation)$$L(x) = f(a) + f'(a)(x - a)$$

For \(x\) near \(a\), \(f(x) \approx L(x)\). The tangent line "looks like" the function when zoomed in.

Differential
\(dy = f'(x)\,dx \approx \Delta y\)
Small change in output ≈ \(f'(x)\) × small change in input.
Example
\(\sqrt{9.1} \approx \sqrt{9} + \frac{1}{2\sqrt{9}}(0.1) = 3 + \frac{0.1}{6} \approx 3.0167\)
L'Hôpital's Rule
L'Hôpital's Rule KEY
If \(\displaystyle\lim \frac{f(x)}{g(x)}\) gives \(\dfrac{0}{0}\) or \(\dfrac{\infty}{\infty}\), then: $$\lim \frac{f(x)}{g(x)} = \lim \frac{f'(x)}{g'(x)}$$ (Differentiate numerator and denominator separately — NOT the quotient rule.)
Only applies to \(\frac{0}{0}\) or \(\frac{\infty}{\infty}\). If you get \(\frac{3}{0}\) or \(\frac{5}{2}\), that's already the limit — do NOT use L'Hôpital.
Indeterminate FormStrategy
\(0/0\) or \(\infty/\infty\)Apply L'Hôpital directly
\(0 \cdot \infty\)Rewrite as \(0/(1/\infty)\) → \(0/0\) form
\(\infty - \infty\)Combine fractions / rationalize first
\(1^\infty,\ 0^0,\ \infty^0\)Take \(\ln\), apply L'Hôpital, then \(e^{\text{result}}\)
Practice Problems
FRQA ladder 10 ft long leans against a wall. The bottom slides away at 2 ft/s. How fast is the top falling when the bottom is 6 ft from the wall?
Related Rates — Ladder Problem
1
Let \(x\) = horizontal distance, \(y\) = height. Constraint: \(x^2 + y^2 = 100\)
2
Differentiate: \(2x\dfrac{dx}{dt} + 2y\dfrac{dy}{dt} = 0\)
3
At \(x = 6\): \(y = \sqrt{100 - 36} = 8\)
4
\(2(6)(2) + 2(8)\dfrac{dy}{dt} = 0 \Rightarrow \dfrac{dy}{dt} = -\dfrac{24}{16} = -1.5\) ft/s
Answer
The top is falling at \(1.5\) ft/s.
HARDFind \(\displaystyle\lim_{x \to 0^+} x^x\)
L'Hôpital — \(0^0\) form
1
Let \(L = \lim_{x\to 0^+} x^x\). Take \(\ln\): \(\ln L = \lim_{x\to 0^+} x\ln x\) → \(0 \cdot (-\infty)\) form
2
Rewrite: \(\lim_{x\to 0^+} \dfrac{\ln x}{1/x}\) → \(-\infty/\infty\) form → apply L'Hôpital
3
\(= \lim_{x\to 0^+} \dfrac{1/x}{-1/x^2} = \lim_{x\to 0^+} (-x) = 0\)
4
So \(\ln L = 0 \Rightarrow L = e^0 = 1\)
Answer
\(\lim_{x\to 0^+} x^x = 1\)
Unit 5

Analytical Applications of Differentiation

MVT, EVT, extrema, concavity, and optimization — the calculus of shape.

Extreme Value Theorem (EVT)
If \(f\) is continuous on \([a,b]\), then \(f\) attains both an absolute max and absolute min on \([a,b]\).
Rolle's Theorem
If \(f\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \(f(a) = f(b)\), then \(\exists\, c \in (a,b)\) with \(f'(c) = 0\).
Mean Value Theorem (MVT) KEY
If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\): $$f'(c) = \frac{f(b) - f(a)}{b - a} \text{ for some } c \in (a,b)$$ The instantaneous rate of change equals the average rate of change somewhere.
MVT: The tangent at some point is parallel to the secant from a to b
Critical Points & Extrema
Critical Point
\(f'(c) = 0\) or \(f'(c)\) DNE
Every local extremum is a critical point. But not every critical point is an extremum (e.g., \(f(x) = x^3\) at \(x=0\)).
First Derivative Test
\(f': + \to -\) at \(c\) → local MAX
\(f': - \to +\) at \(c\) → local MIN
No sign change → no extremum
Second Derivative Test
\(f'(c)=0\) and \(f''(c) < 0\) → local MAX
\(f'(c)=0\) and \(f''(c) > 0\) → local MIN
\(f''(c) = 0\) → inconclusive
Finding Absolute Extrema on [a, b]
Find all critical points in \((a, b)\).
Evaluate \(f\) at each critical point AND the endpoints \(a\), \(b\).
The largest value is the absolute max; the smallest is the absolute min.
Concavity & Inflection Points
Concave Up
\(f''(x) > 0\)
Tangent lines lie below curve. Like ∪. Think "cup holds water."
Concave Down
\(f''(x) < 0\)
Tangent lines lie above curve. Like ∩.
Inflection Point
A point where concavity changes (up to down or vice versa). Must verify that \(f''\) changes sign — just having \(f''(c) = 0\) is not enough!
Concavity, Inflection Points, and Local Extrema on one graph

Gold = f(x), Blue = f'(x), Green = f''(x). Notice inflection at f'' = 0 with sign change.

Curve Sketching Checklist
Domain & intercepts: where is \(f\) defined? Find zeros and \(f(0)\).
Asymptotes: \(\lim_{x\to\pm\infty} f(x)\) for horizontal; denom = 0 for vertical.
Sign of \(f'\): solve \(f'=0\), build sign chart → increasing/decreasing intervals.
Local extrema: apply 1st or 2nd derivative test at critical points.
Sign of \(f''\): solve \(f''=0\), build sign chart → concavity intervals.
Inflection points: where concavity changes sign.
Sketch: plot key points, connect with proper shape.
Optimization
Identify the quantity to maximize/minimize (objective function).
Write a constraint equation relating the variables.
Use constraint to reduce objective to ONE variable.
Differentiate, set \(= 0\), find critical points.
Verify max/min using 1st or 2nd derivative test, or check endpoints.
Answer in context with units.
Most common setups: max area given fixed perimeter, min material for fixed volume, max revenue, closest point on curve to a given point.

Differential Equations

Slope fields, separable DEs, Euler's method, and the logistic model.

Slope Fields

A slope field for \(\dfrac{dy}{dx} = F(x,y)\) draws a short line segment at each point \((x,y)\) with slope \(F(x,y)\). Solution curves flow along these segments.

Slope field: dy/dx = y (exponential growth)
Slope field: dy/dx = x − y
If the DE depends only on \(y\), slopes are constant along horizontal lines. If only on \(x\), slopes are constant along vertical lines.
Separable Differential Equations
Separate: all \(y\) with \(dy\) on one side; all \(x\) with \(dx\) on the other.
Integrate both sides.
Solve for \(y\).
Apply initial condition to find \(C\).
Exponential Growth/Decay
\(\dfrac{dy}{dt} = ky \implies y = Ce^{kt}\)
\(k>0\): growth. \(k<0\): decay. \(C = y(0)\).
Half-life
\(t_{1/2} = \dfrac{\ln 2}{|k|},\quad t_{\text{double}} = \dfrac{\ln 2}{k}\)
When integrating \(\int \frac{dy}{y} = \ln|y|\), the constant \(C\) is in the exponent after solving: \(y = Ae^{kx}\) NOT \(y = e^{kx} + C\).
Euler's Method BC
Euler's Method Algorithm
Given \(\dfrac{dy}{dx} = F(x,y)\), starting point \((x_0, y_0)\), step size \(h\): $$x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h \cdot F(x_n,\, y_n)$$
Euler's Method approximating dy/dx = y, y(0)=1 (true solution: e^x)

Gold = true solution \(e^x\), Blue = Euler approximation (step \(h=0.5\)). Concave up → Euler underestimates.

Logistic Model BC
Logistic Differential Equation$$\frac{dP}{dt} = kP\!\left(1 - \frac{P}{M}\right)$$
Logistic Solution
\(P(t) = \dfrac{M}{1+Ae^{-kt}}\)
\(A = \dfrac{M-P_0}{P_0}\)
Key Properties
Max growth rate at \(P = M/2\)
Inflection at \(P = M/2\)
\(\lim_{t\to\infty}P(t) = M\)
Logistic curve: S-shaped growth toward carrying capacity M

Inflection point at \(P = M/2\) — maximum growth rate. After this point, growth decelerates.

Sequences & Infinite Series

Every convergence test, power series, Taylor/Maclaurin series, and the Lagrange error bound.

Sequences

A sequence \(\{a_n\}\) converges if \(\lim_{n\to\infty} a_n = L\) (finite). Otherwise diverges.

Geometric Sequence
\(a_n = ar^{n-1}\)
Converges iff \(|r| < 1\)
Growth Hierarchy \((n\to\infty)\)
\(\ln n \ll n^p \ll a^n \ll n! \ll n^n\)
Geometric sequences: convergent (|r|<1) vs divergent (|r|>1)
Geometric Series & p-Series
Geometric Series ★ Most Important
\(\displaystyle\sum_{n=0}^{\infty} ar^n = \frac{a}{1-r},\quad |r| < 1\)
Partial sum: \(S_n = a\dfrac{1-r^n}{1-r}\). Diverges if \(|r| \ge 1\).
p-Series ★ Must Know
\(\displaystyle\sum_{n=1}^{\infty} \frac{1}{n^p}:\quad\text{converges if } p > 1,\quad\text{diverges if } p \le 1\)
Harmonic series \(\sum 1/n\) diverges (\(p=1\)).
Partial sums of geometric series converging (r = 0.5, a = 1) → 2
All Convergence Tests
nth Term (Divergence) Test — Always Check First
If \(\lim_{n\to\infty} a_n \neq 0\), then \(\sum a_n\) diverges.
If \(\lim a_n = 0\): INCONCLUSIVE — does NOT prove convergence.
TestWhen to UseCondition
Integral Testf(n) continuous, positive, decreasing\(\sum a_n\) and \(\int_1^\infty f\,dx\) same behavior
Direct ComparisonSeries resembles known series\(0 \le a_n \le b_n\): if \(\sum b_n\) conv → \(\sum a_n\) conv
Limit ComparisonRational-looking, similar to \(p\)-series\(\lim a_n/b_n = L \in (0,\infty)\) → same behavior
Ratio Test ★Contains \(n!\) or \(a^n\)\(L = \lim|a_{n+1}/a_n|\): \(L<1\) conv, \(L>1\) div, \(L=1\) inconcl.
Root TestEverything raised to nth power\(L = \lim\sqrt[n]{|a_n|}\): same criteria
AST ★Alternating signs \((-1)^n\)\(b_n > 0\), decreasing, \(\to 0\) → converges
Absolute Convergence
\(\sum|a_n|\) converges \(\Rightarrow \sum a_n\) converges
AST Error Bound ★
\(|S - S_n| \le b_{n+1}\)
Error ≤ first unused term.
Power Series
Power Series centered at x = a$$\sum_{n=0}^{\infty} c_n(x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots$$
Radius of Convergence
\(R = \lim\left|\dfrac{c_n}{c_{n+1}}\right|\)
Converges for \(|x-a| < R\). Check endpoints separately!
Term-by-term calculus
\(\dfrac{d}{dx}\sum c_n(x-a)^n = \sum nc_n(x-a)^{n-1}\)
Same radius R. Endpoints may change.
Taylor & Maclaurin Series
Taylor Series for f centered at x = a$$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n$$
The 6 Essential Maclaurin Series — Memorize Every One
\(e^x\) — all \(x\)
\(e^x = \displaystyle\sum_{n=0}^{\infty}\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots\)
\(\sin x\) — all \(x\)
\(\sin x = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{6} + \frac{x^5}{120} - \cdots\)
\(\cos x\) — all \(x\)
\(\cos x = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \cdots\)
\(\frac{1}{1-x}\) — \(|x|<1\)
\(\dfrac{1}{1-x} = \displaystyle\sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots\)
\(\ln(1+x)\) — \(-1 < x \le 1\)
\(\ln(1+x) = \displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n+1}x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots\)
\(\arctan x\) — \(|x| \le 1\)
\(\arctan x = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{2n+1} = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\)
Substitution is the fastest technique: to find the series for \(e^{x^2}\), replace every \(x\) with \(x^2\) in the \(e^x\) series. Same for \(\sin(x^3)\), \(\cos(2x)\), etc.
Error Bounds
Lagrange Error Bound Critical AP Topic
If \(T_n(x)\) is the \(n\)th-degree Taylor polynomial for \(f\) centered at \(a\): $$|f(x) - T_n(x)| \le \frac{M \cdot |x-a|^{n+1}}{(n+1)!}$$ where \(M = \max|f^{(n+1)}|\) on the interval between \(a\) and \(x\).
AST Error (simpler)
\(|S - S_n| \le b_{n+1}\)
Use for alternating series — error ≤ first unused term.
When to use which
Alternating series → AST bound (simpler)
Non-alternating (\(e^x\) type) → Lagrange bound
