Unit 1

Limits & Continuity

The foundation of calculus. Formal definitions, limit laws, special trig limits, continuity, IVT, and the Squeeze Theorem.

Informal & Formal Definition of a Limit

The limit of \(f(x)\) as \(x \to c\) equals \(L\) means \(f(x)\) gets arbitrarily close to \(L\) as \(x\) gets close (but never equal) to \(c\).

ε–δ Formal Definition
\(\displaystyle\lim_{x \to c} f(x) = L\) means: for every \(\varepsilon > 0\), there exists \(\delta > 0\) such that $$0 < |x - c| < \delta \implies |f(x) - L| < \varepsilon$$
What ε and δ actually mean
Think of it as a game: your opponent picks any tolerance \(\varepsilon\) (how close \(f(x)\) must get to \(L\)). You win if you can find a neighborhood of radius \(\delta\) around \(c\) that forces \(f(x)\) within \(\varepsilon\) of \(L\). If you can always win, the limit is \(L\).
Why we write 0 < |x − c|
The strict inequality \(0 < |x-c|\) means \(x \neq c\). The limit describes behavior near \(c\), not at it. \(f(c)\) may be undefined, or completely different from \(L\) — the limit doesn't care.
AP Exam tip
You'll rarely need to prove limits using ε–δ on the AP exam. But you must understand that the limit is about approach behavior, not the function's value at the point.
Limit Laws
Sum / Difference
\(\lim[f \pm g] = \lim f \pm \lim g\)
Constant Multiple
\(\lim[c \cdot f(x)] = c \cdot \lim f(x)\)
Product
\(\lim[f \cdot g] = \lim f \cdot \lim g\)
Quotient
\(\displaystyle\lim\frac{f}{g} = \frac{\lim f}{\lim g}, \quad \lim g \neq 0\)
Power
\(\lim[f(x)]^n = [\lim f(x)]^n\)
Composition
\(\lim_{x\to c} f(g(x)) = f\!\left(\lim_{x\to c} g(x)\right)\)
only if \(f\) is continuous at \(\lim g\)
Special Limits — Memorize These
Trig #1 KEY
\(\displaystyle\lim_{x \to 0} \frac{\sin x}{x} = 1\)
Trig #2 KEY
\(\displaystyle\lim_{x \to 0} \frac{1 - \cos x}{x} = 0\)
Natural Base
\(\displaystyle\lim_{n \to \infty}\!\left(1 + \frac{1}{n}\right)^n = e\)
General Form
\(\displaystyle\lim_{x \to 0}(1+x)^{1/x} = e\)
Exponential
\(\displaystyle\lim_{x \to 0} \frac{e^x - 1}{x} = 1\)
Logarithm
\(\displaystyle\lim_{x \to 0} \frac{\ln(1+x)}{x} = 1\)
Geometric proof sketch
For small \(x > 0\), compare areas: \(\text{triangle} \le \text{sector} \le \text{bigger triangle}\). This gives \(\cos x \le \frac{\sin x}{x} \le \frac{1}{\cos x}\). As \(x \to 0\), both sides → 1, so by the Squeeze Theorem, \(\frac{\sin x}{x} \to 1\).
Using it on the exam
Any limit of the form \(\dfrac{\sin(u)}{u}\) as \(u \to 0\) equals 1. For \(\dfrac{\sin(3x)}{x}\), multiply and divide by 3 to get \(3 \cdot \dfrac{\sin(3x)}{3x} \to 3\).
Example
\(\displaystyle\lim_{x \to 0} \frac{\sin(5x)}{2x} = \frac{5}{2}\lim_{x \to 0}\frac{\sin(5x)}{5x} = \frac{5}{2} \cdot 1 = \frac{5}{2}\)
One-Sided Limits
Two-sided limit exists if and only if $$\lim_{x \to c} f(x) = L \iff \lim_{x \to c^-} f(x) = L \text{ and } \lim_{x \to c^+} f(x) = L$$
Limits at Infinity & Asymptotes
Rational Functions — Degree Rule
\(\deg(\text{num}) < \deg(\text{den})\): limit \(= 0\)
\(\deg(\text{num}) = \deg(\text{den})\): limit \(= \frac{\text{lead coeff}}{\text{lead coeff}}\)
\(\deg(\text{num}) > \deg(\text{den})\): limit \(= \pm\infty\)
Growth Hierarchy (as \(x \to \infty\))
\(\ln x \ll x^n \ll a^x \ll x! \ll x^x\)
Squeeze Theorem
Squeeze Theorem
If \(g(x) \le f(x) \le h(x)\) near \(x = c\), and \(\displaystyle\lim_{x \to c} g(x) = \lim_{x \to c} h(x) = L\), then \(\displaystyle\lim_{x \to c} f(x) = L\).
Classic example
\(\displaystyle\lim_{x \to 0} x^2 \sin\!\left(\frac{1}{x}\right) = 0\) Since \(-1 \le \sin(1/x) \le 1\), we have \(-x^2 \le x^2\sin(1/x) \le x^2\). Both bounds \(\to 0\), so the limit \(= 0\).
When to use it
Use Squeeze whenever you see a bounded function (like \(\sin\), \(\cos\)) multiplied by something going to zero. The bounded part is "squeezed" to zero.
Continuity
Three Conditions for Continuity at \(x = c\)
1. \(f(c)\) is defined
2. \(\displaystyle\lim_{x \to c} f(x)\) exists
3. \(\displaystyle\lim_{x \to c} f(x) = f(c)\)

All three must hold. Fail any one → discontinuity at \(c\).
Removable (Hole)
Limit exists but \(\neq f(c)\). "Fixable" by redefining \(f(c)\).
Jump
\(\lim_{c^-} \neq \lim_{c^+}\). Both one-sided limits exist but differ.
Infinite (Asymptote)
\(\lim = \pm\infty\). Vertical asymptote at \(x = c\).
Intermediate Value Theorem (IVT)
Intermediate Value Theorem
If \(f\) is continuous on \([a, b]\) and \(M\) is any value between \(f(a)\) and \(f(b)\), then there exists at least one \(c \in (a, b)\) such that \(f(c) = M\).
Proving a zero exists
If \(f(a) < 0\) and \(f(b) > 0\) (or vice versa) and \(f\) is continuous, then \(0\) is between \(f(a)\) and \(f(b)\), so IVT guarantees a root \(c \in (a,b)\).
Typical AP question
"Show that f(x) = x³ − 2x − 5 has a root on [2, 3]." f(2) = 8 − 4 − 5 = −1 < 0 f(3) = 27 − 6 − 5 = 16 > 0 f is continuous (polynomial), so by IVT, ∃ c ∈ (2,3) with f(c) = 0. ✓
Common mistakes
IVT guarantees existence, NOT uniqueness. Always verify continuity first. IVT cannot tell you the exact value of \(c\).
Unit 2

Basic Differentiation

Definition of the derivative, all core rules, and the complete derivative tables for trig, exponential, and logarithmic functions.

Definition of the Derivative
Limit Definition
\(\displaystyle f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}\)
Alternate Form
\(\displaystyle f'(a) = \lim_{x \to a} \frac{f(x)-f(a)}{x-a}\)
Example: Find f'(x) for f(x) = x²
\(f'(x) = \lim_{h \to 0} \frac{(x+h)^2 - x^2}{h}\) \(= \lim_{h \to 0} \frac{x^2 + 2xh + h^2 - x^2}{h}\) \(= \lim_{h \to 0} \frac{2xh + h^2}{h} = \lim_{h \to 0} (2x + h) = 2x\)
Key steps
1. Expand \(f(x+h)\). 2. Subtract \(f(x)\). 3. Factor \(h\) from numerator. 4. Cancel \(h\). 5. Take limit.
Differentiability vs Continuity
Differentiable \(\Rightarrow\) continuous. But continuous does NOT imply differentiable. Fails at: corners, cusps, vertical tangents, jumps.
Core Differentiation Rules
Constant Rule
\(\dfrac{d}{dx}[c] = 0\)
Power Rule MOST USED
\(\dfrac{d}{dx}[x^n] = nx^{n-1}\)
Constant Multiple
\(\dfrac{d}{dx}[c \cdot f] = c \cdot f'(x)\)
Sum / Difference
\(\dfrac{d}{dx}[f \pm g] = f'(x) \pm g'(x)\)
Product Rule KEY
\(\dfrac{d}{dx}[u \cdot v] = u'v + uv'\)
"First d-Second plus Second d-First"
Quotient Rule KEY
\(\dfrac{d}{dx}\!\left[\dfrac{u}{v}\right] = \dfrac{u'v - uv'}{v^2}\)
"Low dHigh minus High dLow, over Low squared"
Product Rule example
Differentiate \(f(x) = x^2 \sin x\) \(f'(x) = (2x)(\sin x) + (x^2)(\cos x) = 2x\sin x + x^2\cos x\)
Quotient Rule example
Differentiate \(g(x) = \dfrac{x^2}{e^x}\) \(g'(x) = \dfrac{(2x)(e^x) - (x^2)(e^x)}{(e^x)^2} = \dfrac{e^x(2x - x^2)}{e^{2x}} = \dfrac{x(2-x)}{e^x}\)
Common mistake
Quotient rule: the numerator is \(u'v - uv'\), NOT \(uv' - u'v\). The derivative of the top goes first in the numerator.
Derivatives of Trigonometric Functions
f(x)f'(x)Memory tip
\(\sin x\)\(\cos x\)
\(\cos x\)\(-\sin x\)
\(\tan x\)\(\sec^2 x\)
\(\cot x\)\(-\csc^2 x\)Negative sign
\(\sec x\)\(\sec x \tan x\)"sec tan"
\(\csc x\)\(-\csc x \cot x\)Negative, "csc cot"
The "co-functions" (cos, cot, csc) all have a negative sign in their derivatives. Remember: co = negative.
Exponential & Logarithmic Derivatives
Natural Exponential
\(\dfrac{d}{dx}[e^x] = e^x\)
Only function equal to its own derivative.
General Exponential
\(\dfrac{d}{dx}[a^x] = a^x \ln a\)
Natural Log
\(\dfrac{d}{dx}[\ln x] = \dfrac{1}{x}, \quad x > 0\)
General Log
\(\dfrac{d}{dx}[\log_a x] = \dfrac{1}{x \ln a}\)
Absolute Value Log
\(\dfrac{d}{dx}[\ln|x|] = \dfrac{1}{x}, \quad x \neq 0\)
Tangent & Normal Lines
Tangent Line at \((a, f(a))\)
\(y - f(a) = f'(a)(x - a)\)
Normal Line at \((a, f(a))\)
\(y - f(a) = -\dfrac{1}{f'(a)}(x - a)\)
Perpendicular to tangent; slope is negative reciprocal.
Unit 3

Advanced Differentiation

Chain rule, implicit differentiation, derivatives of inverse functions, all six inverse trig derivatives, and logarithmic differentiation.

Chain Rule
Chain Rule — Composite Functions $$\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$$
Leibniz Form
\(\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}\)
Chain + Power
\(\dfrac{d}{dx}[u^n] = nu^{n-1} \cdot u'\)
Chain + Trig
\(\dfrac{d}{dx}[\sin u] = \cos u \cdot u'\)
Chain + Exp
\(\dfrac{d}{dx}[e^u] = e^u \cdot u'\)
Chain + Log
\(\dfrac{d}{dx}[\ln u] = \dfrac{u'}{u}\)
General Power
\(\dfrac{d}{dx}[a^u] = a^u \ln a \cdot u'\)
The "peel the onion" method
Identify the outermost function. Differentiate it, leaving the inside alone. Then multiply by the derivative of the inside. Keep repeating for nested chains.
Example: simple chain
f(x) = sin(x³) Outer: sin(·), derivative = cos(·) Inner: x³, derivative = 3x² f'(x) = cos(x³) · 3x²
Example: nested (triple chain)
f(x) = e^{sin(x²)} Layer 1: e^(·), stays as e^{sin(x²)} Layer 2: sin(·) → cos(·) = cos(x²) Layer 3: x² → 2x f'(x) = e^{sin(x²)} · cos(x²) · 2x
Common mistake
Forgetting to multiply by the inner derivative! d/dx[sin(x²)] ≠ cos(x²). You must multiply by 2x.
Implicit Differentiation
Differentiate every term with respect to \(x\). Terms with \(y\) get an extra factor of \(\frac{dy}{dx}\) (chain rule).
Collect all \(\frac{dy}{dx}\) terms on one side.
Factor out \(\frac{dy}{dx}\) and divide.
Key Pattern
\(\dfrac{d}{dx}[y^n] = n\, y^{n-1} \cdot \dfrac{dy}{dx}\)
Example: \(\frac{d}{dx}[x^2 + y^2] = 2x + 2y\frac{dy}{dx} = 0 \implies \frac{dy}{dx} = -\frac{x}{y}\)
Example: Find dy/dx for x³ + y³ = 6xy
Differentiate both sides: 3x² + 3y²(dy/dx) = 6y + 6x(dy/dx) Group dy/dx terms: 3y²(dy/dx) − 6x(dy/dx) = 6y − 3x² dy/dx(3y² − 6x) = 6y − 3x² dy/dx = (6y − 3x²)/(3y² − 6x) = (2y − x²)/(y² − 2x)
Finding d²y/dx² implicitly
Differentiate dy/dx implicitly again. Substitute back the expression for dy/dx at the end. This is tested on the AP exam.
Inverse Function Derivative Theorem
Inverse Function Derivative
If \(f\) and \(f^{-1}\) are inverse functions and \(f\) is differentiable:
$$(f^{-1})'(x) = \frac{1}{f'(f^{-1}(x))}$$ Equivalently: \(\displaystyle\frac{dx}{dy} = \frac{1}{dy/dx}\)
Classic AP question format
"f(3) = 7 and f'(3) = 4. Find (f⁻¹)'(7)." Since f(3) = 7, we know f⁻¹(7) = 3. (f⁻¹)'(7) = 1/f'(f⁻¹(7)) = 1/f'(3) = 1/4
The key insight
The input to \((f^{-1})'\) tells you the output of \(f\). Find where \(f\) produces that output — that's where you evaluate \(f'\).
Derivatives of Inverse Trig Functions
f(x)f'(x)Domain
\(\arcsin x\)\(\dfrac{1}{\sqrt{1-x^2}}\)\(|x| < 1\)
\(\arccos x\)\(-\dfrac{1}{\sqrt{1-x^2}}\)\(|x| < 1\)
\(\arctan x\)\(\dfrac{1}{1+x^2}\)all \(x\)
\(\text{arccot}\, x\)\(-\dfrac{1}{1+x^2}\)all \(x\)
\(\text{arcsec}\, x\)\(\dfrac{1}{|x|\sqrt{x^2-1}}\)\(|x| > 1\)
\(\text{arccsc}\, x\)\(-\dfrac{1}{|x|\sqrt{x^2-1}}\)\(|x| > 1\)
With chain rule: \(\dfrac{d}{dx}[\arctan(u)] = \dfrac{u'}{1+u^2}\). Apply same pattern to all six. The "co" versions (arccos, arccot, arccsc) are all negative.
Logarithmic Differentiation

Use when differentiating complex products/quotients or variable-base exponentials like \(x^{\sin x}\).

Take \(\ln\) of both sides: \(\ln y = \ln[f(x)]\)
Simplify using log properties: \(\ln(ab) = \ln a + \ln b\), \(\ln(a^n) = n\ln a\)
Differentiate both sides implicitly: \(\dfrac{y'}{y} = [\cdots]\)
Solve: \(y' = y \cdot [\cdots]\), then substitute \(y = f(x)\)
Classic: \(y = x^x\)
\(\ln y = x\ln x \implies \dfrac{y'}{y} = \ln x + 1 \implies y' = x^x(\ln x + 1)\)
Unit 4

Contextual Applications of Differentiation

Motion along a line, related rates, linearization, and L'Hôpital's Rule for all indeterminate forms.

Motion Along a Line
Position
\(s(t)\) or \(x(t)\)
Velocity
\(v(t) = s'(t)\)
Acceleration
\(a(t) = v'(t) = s''(t)\)
Speed
\(|v(t)|\) (always \(\ge 0\))
Speeding Up
\(v\) and \(a\) have the same sign
Slowing Down
\(v\) and \(a\) have opposite signs
Displacement vs. Total Distance
Displacement = \(\int_a^b v(t)\,dt\) — can be negative (net change in position).
Total distance = \(\int_a^b |v(t)|\,dt\) — always positive.
Finding when particle changes direction
1. Solve v(t) = 0 to find candidates. 2. Check that v CHANGES SIGN at that t. v goes + → − : particle reverses direction (was moving right, now left) v goes − → + : particle reverses (was left, now right)
Example motion analysis
s(t) = t³ − 6t² + 9t v(t) = 3t² − 12t + 9 = 3(t−1)(t−3) = 0 at t = 1, 3 a(t) = 6t − 12 At t = 1: v = 0, a = −6 → particle stops, then moves left At t = 2: v < 0, a = 0 → moving left, not speeding/slowing (inflection of v) At t = 3: v = 0, a = 6 → particle stops, then moves right
Related Rates
Draw a diagram. Label all quantities that change with time as variables.
Write an equation relating the variables (geometry, trig, Pythagorean theorem…).
Differentiate both sides with respect to \(t\). Every variable gets a rate \(\frac{d(\cdot)}{dt}\).
Substitute known values (only after differentiating!) and solve for the unknown rate.
Circle Area
\(A = \pi r^2 \implies \dfrac{dA}{dt} = 2\pi r \cdot \dfrac{dr}{dt}\)
Sphere Volume
\(V = \tfrac{4}{3}\pi r^3 \implies \dfrac{dV}{dt} = 4\pi r^2 \cdot \dfrac{dr}{dt}\)
Pythagorean (Ladder)
\(a^2 + b^2 = c^2\)
\(2a\dot{a} + 2b\dot{b} = 2c\dot{c}\)
Cone Volume
\(V = \tfrac{1}{3}\pi r^2 h\)
Use similar triangles to eliminate one variable first.
Ladder sliding down a wall
10 ft ladder: foot sliding out at 2 ft/s. How fast is top falling when foot is 6 ft from wall? x² + y² = 100 → 2x(dx/dt) + 2y(dy/dt) = 0 When x = 6: y = √(100−36) = 8 2(6)(2) + 2(8)(dy/dt) = 0 dy/dt = −24/16 = −3/2 ft/s (falling at 1.5 ft/s)
Common mistake
Never substitute known values BEFORE differentiating. The values describe a snapshot in time — after differentiation is the right moment.
Linear Approximation (Linearization)
Linearization at \(x = a\) $$L(x) = f(a) + f'(a)(x - a)$$
Differential
\(dy = f'(x)\,dx \approx \Delta y\)
For small \(dx\), the differential approximates the actual change in \(y\).
L'Hôpital's Rule KEY
L'Hôpital's Rule
If \(\lim \dfrac{f(x)}{g(x)}\) gives \(\dfrac{0}{0}\) or \(\dfrac{\infty}{\infty}\), then: $$\lim \frac{f(x)}{g(x)} = \lim \frac{f'(x)}{g'(x)}$$ provided the right-side limit exists.
FormStrategy
\(0/0,\ \infty/\infty\)Apply L'Hôpital directly
\(0 \cdot \infty\)Rewrite as \(0/(1/\infty)\) or \(\infty/(1/0)\), then L'Hôpital
\(\infty - \infty\)Combine fractions or rationalize, then L'Hôpital
\(1^\infty,\ 0^0,\ \infty^0\)Take \(\ln\), apply L'Hôpital to \(\ln\) form, exponentiate answer
0/0 form
\(\lim_{x \to 0} \frac{\sin x}{x} = \frac{\cos x}{1}\Big|_{x=0} = 1\)
∞/∞ form
\(\lim_{x \to \infty} \frac{\ln x}{x} = \frac{1/x}{1} = \frac{1}{x} \to 0\)
1^∞ form
\(\lim_{x \to 0} (1+x)^{1/x}\) Let L = limit. ln L = lim (1/x)·ln(1+x) = lim ln(1+x)/x Apply L'Hôpital: = lim (1/(1+x))/1 = 1 So ln L = 1, therefore L = e^1 = e ✓
Critical warning
L'Hôpital ONLY applies to indeterminate forms. If lim f(x)/g(x) = 3/0 or 5/2, it's NOT indeterminate — just compute the limit directly.
Unit 5

Analytical Applications of Differentiation

MVT, EVT, Rolle's Theorem, extrema, concavity, curve sketching, and optimization — the analysis toolbox.

The Big Three Theorems
Extreme Value Theorem (EVT)
If \(f\) is continuous on \([a,b]\), then \(f\) attains both an absolute maximum and minimum on \([a,b]\).
Rolle's Theorem
If \(f\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \(f(a) = f(b)\), then \(\exists\, c \in (a,b)\) with \(f'(c) = 0\).
Mean Value Theorem (MVT) KEY
If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), then \(\exists\, c \in (a,b)\) such that: $$f'(c) = \frac{f(b) - f(a)}{b - a}$$ Instantaneous rate of change equals the average rate of change somewhere.
What MVT actually says
The average slope of the secant line from \(a\) to \(b\) must equal the slope of the tangent line at some interior point. Think of it: if your average speed on a road trip was 60 mph, at some moment your speedometer read exactly 60 mph.
AP consequence: proving a function has exactly one zero
If \(f'(x) > 0\) everywhere (MVT implies \(f\) is strictly increasing), then \(f\) can cross zero at most once.
AP FRQ style
"Must there exist a c in (1,4) where f'(c) = 3?" Check: (f(4)−f(1))/(4−1) = avg rate of change. If = 3 and f is continuous/differentiable → yes, by MVT.
Critical Points & Extrema Tests
Critical Point
\(f'(c) = 0\) or \(f'(c)\) does not exist
Candidates for local extrema. Not all critical points are extrema.
First Derivative Test
\(f'\): \(+ \to -\) → local MAX
\(f'\): \(- \to +\) → local MIN
No sign change → no extremum
Second Derivative Test
\(f'(c) = 0\) and \(f''(c) < 0\) → local MAX
\(f'(c) = 0\) and \(f''(c) > 0\) → local MIN
\(f''(c) = 0\) → inconclusive
Concavity & Inflection Points
Concave Up
\(f''(x) > 0\)
Tangent lines lie below curve. Like a cup ∪.
Concave Down
\(f''(x) < 0\)
Tangent lines lie above curve. Like a cap ∩.
Inflection Point
A point where concavity changes sign. Find where \(f''(x) = 0\) or DNE, then verify \(f''\) changes sign. Just \(f''(c) = 0\) alone is not enough!
Curve Sketching Checklist
Domain & intercepts: Where is \(f\) defined? Find \(x\)- and \(y\)-intercepts.
Asymptotes: Horizontal (\(\lim_{x\to\pm\infty}\)), vertical (denom = 0).
Inc / Dec: Find \(f'\), solve \(f'=0\), build sign chart.
Local extrema: Apply 1st or 2nd derivative test at critical points.
Concavity: Find \(f''\), solve \(f''=0\), build sign chart for concavity intervals.
Inflection points: Where concavity changes.
Sketch: Plot key points; connect with correct shape.
Optimization
Identify the quantity to maximize/minimize (objective function).
Write a constraint equation relating the variables.
Use the constraint to reduce objective to one variable.
Differentiate, set equal to zero, find critical points.
Verify max/min using 1st or 2nd derivative test, or check endpoints if on a closed interval.
Answer in context with units.
Max area with fixed perimeter
Rectangle with perimeter 40. Maximize area. Constraint: 2l + 2w = 40 → l = 20 − w Objective: A = lw = (20−w)w = 20w − w² dA/dw = 20 − 2w = 0 → w = 10, l = 10 Max area = 100 (it's a square!)
Closest point on curve to a point
Minimize D² = (x − 0)² + (y − 3)² with y = x² D² = x² + (x² − 3)² = x⁴ − 5x² + 9 d(D²)/dx = 4x³ − 10x = 2x(2x² − 5) = 0 x = 0 or x = ±√(5/2)
Unit 6

Integration & Accumulation of Change

Riemann sums, FTC, all antiderivatives, u-substitution, integration by parts, partial fractions, and improper integrals.

Riemann Sums
Subinterval Width
\(\Delta x = \dfrac{b-a}{n}\)
Left Sum
\(L_n = \Delta x \displaystyle\sum_{i=0}^{n-1} f(x_i)\)
Right Sum
\(R_n = \Delta x \displaystyle\sum_{i=1}^{n} f(x_i)\)
Trapezoidal Rule KEY
\(T_n = \dfrac{\Delta x}{2}\bigl[f(x_0) + 2f(x_1) + 2f(x_2) + \cdots + 2f(x_{n-1}) + f(x_n)\bigr]\)
Average of Left and Right sums. Overestimates when concave up; underestimates when concave down.
Fundamental Theorem of Calculus
FTC Part 1 — Evaluation Theorem MOST USED
If \(F'(x) = f(x)\), then: $$\int_a^b f(x)\,dx = F(b) - F(a) = \bigl[F(x)\bigr]_a^b$$
FTC Part 2 — Antiderivative Theorem
If \(g(x) = \displaystyle\int_a^x f(t)\,dt\), then \(g'(x) = f(x)\).

With chain rule: \(\dfrac{d}{dx}\displaystyle\int_a^{g(x)} f(t)\,dt = f(g(x)) \cdot g'(x)\)
Why the chain rule appears
When the upper limit is a function of \(x\) rather than just \(x\), you must multiply by the derivative of that upper limit. This is just the chain rule applied to the composition.
Example
\(\dfrac{d}{dx}\int_1^{x^3} \cos(t^2)\,dt = \cos(x^6) \cdot 3x^2\) (Plug in upper limit for t, then multiply by derivative of upper limit)
Two variable limits
\(\dfrac{d}{dx}\int_{x}^{x^2} f(t)\,dt = f(x^2)\cdot 2x - f(x)\cdot 1\) Split into two integrals using additive property, then apply FTC2 to each.

\(\sec x \tan x\)\(\sec x + C\)
\(\csc x \cot x\)\(-\csc x + C\)
\(\tan x\)\(\ln|\sec x| + C\)
\(\dfrac{1}{\sqrt{1-x^2}}\)\(\arcsin x + C\)
\(\dfrac{1}{1+x^2}\)\(\arctan x + C\)
U-Substitution
Identify \(u = g(x)\) (usually the "inside" of a composite function).
Compute \(du = g'(x)\,dx\). Solve for \(dx\) if needed.
Rewrite the integral entirely in terms of \(u\).
Integrate with respect to \(u\).
Back-substitute \(u = g(x)\). For definite integrals, change limits to \(u\)-values.
Basic example
\(\int 2x\cos(x^2)\,dx\) u = x², du = 2x dx = \(\int \cos(u)\,du = \sin(u) + C = \sin(x^2) + C\)
Definite integral — change limits
\(\int_0^2 x\,e^{x^2}\,dx\) u = x², du = 2x dx → x dx = du/2 When x = 0: u = 0. When x = 2: u = 4 = \(\tfrac{1}{2}\int_0^4 e^u\,du = \tfrac{1}{2}[e^u]_0^4 = \tfrac{1}{2}(e^4 - 1)\)
When u-sub doesn't work
If you can't get the integrand purely in terms of \(u\) after substituting (leftover \(x\) terms that don't cancel), try integration by parts instead.
Integration by Parts BC
Integration by Parts $$\int u\,dv = uv - \int v\,du$$
LIATE — Choose u from the FIRST applicable category
\(\mathbf{L}\)og · \(\mathbf{I}\)nverse trig · \(\mathbf{A}\)lgebraic · \(\mathbf{T}\)rig · \(\mathbf{E}\)xponential
Standard example
\(\int x e^x\,dx\) u = x (Algebraic), dv = e^x dx du = dx, v = e^x = xe^x − \(\int e^x\,dx\) = xe^x − e^x + C = e^x(x−1) + C
Cyclic integral (solve for I)
\(I = \int e^x \sin x\,dx\) IBP twice: I = e^x sin x − e^x cos x − I 2I = e^x(sin x − cos x) I = \(\frac{e^x(\sin x - \cos x)}{2}\) + C
Log case (u = ln x)
\(\int \ln x\,dx\) u = ln x, dv = dx, du = 1/x dx, v = x = x ln x − \(\int x \cdot \frac{1}{x}\,dx\) = x ln x − x + C
Partial Fraction Decomposition BC
Distinct Linear
\(\dfrac{P(x)}{(x-a)(x-b)} = \dfrac{A}{x-a} + \dfrac{B}{x-b}\)
Repeated Linear
\(\dfrac{P(x)}{(x-a)^2} = \dfrac{A}{x-a} + \dfrac{B}{(x-a)^2}\)
Irreducible Quadratic
\(\dfrac{P(x)}{(x-a)(x^2+bx+c)} = \dfrac{A}{x-a} + \dfrac{Bx+C}{x^2+bx+c}\)
If \(\deg(\text{num}) \ge \deg(\text{den})\), do polynomial long division first before decomposing.
Improper Integrals BC
Infinite Bound
\(\displaystyle\int_a^{\infty} f\,dx = \lim_{t \to \infty}\int_a^t f\,dx\)
Discontinuity at b
\(\displaystyle\int_a^b f\,dx = \lim_{t \to b^-}\int_a^t f\,dx\)
p-Integral Results MEMORIZE
\(\displaystyle\int_1^{\infty} \frac{1}{x^p}\,dx\): converges if \(p > 1\), diverges if \(p \le 1\)
\(\displaystyle\int_0^{1} \frac{1}{x^p}\,dx\): converges if \(p < 1\), diverges if \(p \ge 1\)
Unit 7

Differential Equations

Slope fields, separable DEs, exponential models, Euler's method, and the logistic differential equation.

Slope Fields

A slope field for \(\frac{dy}{dx} = F(x,y)\) draws a short segment with slope \(F(x,y)\) at each point \((x,y)\). Solution curves follow the field's "flow."

Identifying features
If all slopes on a horizontal line \(y = k\) are equal, the DE depends only on \(y\). If slopes along a vertical line \(x = c\) are equal, it depends only on \(x\).
Isoclines
An isocline is a curve where \(F(x,y) = k\) (constant slope). Along \(dy/dx = 0\), the segments are horizontal — this curve shows where solutions have horizontal tangents (potential extrema).
AP strategy
Plug in specific points to compute slopes. Trace a solution curve from an initial condition by following segments. Check signs of \(F(x,y)\) in each region.
Separable Differential Equations
Separate: move all \(y\)-terms with \(dy\) to one side; all \(x\)-terms with \(dx\) to the other.
Integrate both sides.
Solve for \(y\) (if possible).
Apply initial condition to find \(C\).
Exponential Growth/Decay
\(\dfrac{dy}{dt} = ky \implies y = Ce^{kt}\)
\(k > 0\): growth. \(k < 0\): decay. \(C = y(0)\).
Half-life / Doubling
\(t_{1/2} = \dfrac{\ln 2}{|k|}, \quad t_{\text{double}} = \dfrac{\ln 2}{k}\)
Full example
Solve: dy/dx = xy, y(0) = 2 Separate: dy/y = x dx Integrate: ln|y| = x²/2 + C Exponentiate: |y| = e^(x²/2 + C) = Ae^(x²/2) (A = e^C > 0) General solution: y = Ae^(x²/2) Apply IC: 2 = Ae^0 = A Particular solution: y = 2e^(x²/2)
Common mistakes
Don't forget the constant of integration! And: ln|y| + C₁ = x²/2 + C₂ simplifies to ln|y| = x²/2 + C (absorb both into one C). Writing y = e^(x²/2) + C is WRONG — the C must be in the exponent.
Euler's Method BC
Euler's Method
Given \(\dfrac{dy}{dx} = F(x,y)\), start \((x_0, y_0)\), step size \(h\): $$x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h \cdot F(x_n, y_n)$$ Repeat until the target \(x\)-value is reached.
Full example
dy/dx = x + y, y(0) = 1, h = 0.1. Approximate y(0.2). Step 1: x₀=0, y₀=1. F(0,1) = 0+1 = 1 y₁ = 1 + 0.1(1) = 1.1, x₁ = 0.1 Step 2: x₁=0.1, y₁=1.1. F(0.1,1.1) = 0.1+1.1 = 1.2 y₂ = 1.1 + 0.1(1.2) = 1.22, x₂ = 0.2 Approximation: y(0.2) ≈ 1.22
Over/Underestimate
If the solution is concave up, Euler's method underestimates (tangent lines are below the curve). If concave down, it overestimates.
Logistic Differential Equation BC
Logistic Model $$\frac{dP}{dt} = kP\!\left(1 - \frac{P}{M}\right)$$
Logistic Solution
\(P(t) = \dfrac{M}{1 + Ae^{-kt}}, \quad A = \dfrac{M - P_0}{P_0}\)
Key Properties
Max growth rate at \(P = M/2\)
Inflection point: \(P = M/2\)
\(\lim_{t\to\infty} P(t) = M\)
Why the growth rate peaks at P = M/2
The rate is \(f(P) = kP(1-P/M)\). Treat as a parabola in \(P\) — it's maximized at \(P = M/2\). Before that, population accelerates. After, it decelerates toward \(M\).
Finding A from initial condition P(0) = P₀
P(0) = M/(1 + A) = P₀ 1 + A = M/P₀ A = M/P₀ − 1 = (M − P₀)/P₀
AP FRQ question type
You're often asked to: (1) identify \(M\) and \(k\) from the DE, (2) determine when growth rate is maximized (at \(P = M/2\)), (3) determine behavior as \(t \to \infty\).
Unit 8

Applications of Integration

Area between curves, volumes of revolution (disk, washer, shell), arc length, and average value.

Area Between Curves
Vertical slices (integrate in \(x\))
\(A = \displaystyle\int_a^b [\text{top}(x) - \text{bottom}(x)]\,dx\)
Horizontal slices (integrate in \(y\))
\(A = \displaystyle\int_c^d [\text{right}(y) - \text{left}(y)]\,dy\)
If curves cross in the interval, split the integral at each crossing. The top/bottom relationship may switch.
Volumes of Revolution
Disk Method (no hole)
About \(x\)-axis
\(V = \pi\displaystyle\int_a^b [f(x)]^2\,dx\)
About \(y\)-axis
\(V = \pi\displaystyle\int_c^d [f(y)]^2\,dy\)
Washer Method (two curves, hollow)
About \(x\)-axis
\(V = \pi\displaystyle\int_a^b \bigl([R(x)]^2 - [r(x)]^2\bigr)\,dx\)
\(R\) = outer radius, \(r\) = inner radius (both distances from axis)
Rotating about y = k
When rotating about the line \(y = k\), the radius of each function is the distance from the function to the axis, which is \(|f(x) - k|\).
Example: rotate region between y = x² and y = x about y = −1
R(x) = x − (−1) = x + 1 (outer: top function + distance to axis) r(x) = x² − (−1) = x² + 1 (inner: bottom function + distance to axis) V = π∫₀¹ [(x+1)² − (x²+1)²] dx
Key insight
Always draw a cross-section. Identify which function is farther from the axis (outer) and which is closer (inner). The outer radius is always larger.
Shell Method BC
About \(y\)-axis (integrate in \(x\))
\(V = 2\pi\displaystyle\int_a^b x \cdot f(x)\,dx\)
radius = \(x\), height = \(f(x)\)
About \(x\)-axis (integrate in \(y\))
\(V = 2\pi\displaystyle\int_c^d y \cdot f(y)\,dy\)
Shells: slices are parallel to the axis. Disks/washers: slices are perpendicular to the axis. Use shells when the function is given in \(x\) but you're rotating about the \(y\)-axis.
Arc Length BC
Cartesian
\(L = \displaystyle\int_a^b \sqrt{1 + [f'(x)]^2}\,dx\)
In terms of \(y\)
\(L = \displaystyle\int_c^d \sqrt{1 + [g'(y)]^2}\,dy\)
Average Value of a Function
Average Value $$f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx$$
MVT for Integrals
If \(f\) is continuous on \([a,b]\), then \(\exists\, c \in [a,b]\) with \(f(c) = f_{\text{avg}}\). The function equals its average value somewhere.
Unit 9 — BC Only

Parametric, Polar & Vectors

Calculus with parametric curves, polar coordinates, and vector-valued functions — derivatives, arc length, area, and planar motion.

Parametric Equations

A curve is defined by \(x = f(t)\) and \(y = g(t)\). The parameter \(t\) often represents time.

First Derivative (slope)
\(\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}\)
Horizontal tangent: \(dy/dt = 0\) (and \(dx/dt \neq 0\))
Vertical tangent: \(dx/dt = 0\) (and \(dy/dt \neq 0\))
Second Derivative
\(\dfrac{d^2y}{dx^2} = \dfrac{\;d\!\left(\dfrac{dy}{dx}\right)/dt\;}{dx/dt}\)
Arc Length
\(L = \displaystyle\int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt\)
Speed at time \(t\)
\(|v| = \sqrt{\dot{x}^2 + \dot{y}^2}\)
Example: x = t², y = t³ − 3t
dx/dt = 2t, dy/dt = 3t² − 3 dy/dx = (3t² − 3)/(2t) Horizontal tangent: 3t² − 3 = 0 → t = ±1 Vertical tangent: 2t = 0 → t = 0 d²y/dx² = [d/dt(dy/dx)] / (dx/dt) d/dt[(3t²−3)/2t] = d/dt[3t/2 − 3/(2t)] = 3/2 + 3/(2t²) d²y/dx² = [3/2 + 3/(2t²)] / (2t)
Polar Coordinates
Polar ↔ Cartesian
\(x = r\cos\theta,\quad y = r\sin\theta\)
\(r^2 = x^2 + y^2\)
Slope of Polar Curve
\(\dfrac{dy}{dx} = \dfrac{r'\sin\theta + r\cos\theta}{r'\cos\theta - r\sin\theta}\)
Area in Polar Coordinates KEY
Area of polar region $$A = \frac{1}{2}\int_\alpha^\beta r^2\,d\theta = \frac{1}{2}\int_\alpha^\beta [f(\theta)]^2\,d\theta$$
Area between two polar curves
\(A = \dfrac{1}{2}\displaystyle\int_\alpha^\beta \bigl([R(\theta)]^2 - [r(\theta)]^2\bigr)\,d\theta\)
\(R\) = outer, \(r\) = inner. Find \(\alpha, \beta\) by setting \(R = r\).
Common polar curves
r = a: circle of radius a r = 2a cosθ: circle of diameter 2a along x-axis r = a(1 ± cosθ): cardioid r = a + b cosθ: limaçon (inner loop if b > a) r = a cos(nθ): rose (n petals if n odd, 2n if n even) r² = a² cos(2θ): lemniscate (figure-eight)
Finding intersection angles
Set \(R(\theta) = r(\theta)\) and solve. Also check the pole (\(r = 0\)): both curves might pass through it at different angles. Graph carefully.
Symmetry shortcuts
If the curve is symmetric about the \(x\)-axis, integrate from 0 to \(\pi/2\) and double. For a rose \(r = \cos(n\theta)\), each petal spans \(\pi/n\) in \(\theta\).
Vector-Valued Functions

Position vector \(\mathbf{r}(t) = \langle x(t),\, y(t) \rangle\) describes planar motion.

Velocity
\(\mathbf{v}(t) = \mathbf{r}'(t) = \langle x', y' \rangle\)
Acceleration
\(\mathbf{a}(t) = \mathbf{v}'(t) = \langle x'', y'' \rangle\)
Speed
\(|\mathbf{v}(t)| = \sqrt{(x')^2 + (y')^2}\)
Distance traveled
\(\displaystyle\int_a^b |\mathbf{v}(t)|\,dt\)
Position from velocity
\(\mathbf{r}(t) = \mathbf{r}(t_0) + \displaystyle\int_{t_0}^t \mathbf{v}(s)\,ds\)
Unit 10 — BC Only

Infinite Sequences & Series

Every convergence test, geometric and p-series, power series, Taylor/Maclaurin series, and the Lagrange error bound.

Sequences

A sequence \(\{a_n\}\) converges if \(\lim_{n\to\infty} a_n = L\) (finite). Otherwise it diverges.

Geometric Sequence
\(a_n = a \cdot r^{n-1}\)
Converges iff \(|r| < 1\)
Growth hierarchy \((n\to\infty)\)
\(\ln n \ll n^p \ll a^n \ll n! \ll n^n\)
Key Series — Know These Cold
Geometric Series MOST IMPORTANT
\(\displaystyle\sum_{n=0}^{\infty} ar^n = \frac{a}{1-r}, \quad |r| < 1\)
Diverges if \(|r| \ge 1\). Partial sum: \(S_n = a\cdot\dfrac{1-r^n}{1-r}\).
p-Series MUST KNOW
\(\displaystyle\sum_{n=1}^{\infty} \frac{1}{n^p}\): converges if \(p > 1\), diverges if \(p \le 1\)
Harmonic series \(\sum 1/n\): diverges (\(p = 1\)).
All Convergence Tests
nth Term (Divergence) Test
If \(\lim_{n\to\infty} a_n \neq 0\), then \(\sum a_n\) diverges.
If \(\lim a_n = 0\): inconclusive — series may converge or diverge.
Integral Test
If \(f\) is continuous, positive, decreasing on \([1,\infty)\) and \(a_n = f(n)\): \(\sum a_n\) and \(\int_1^\infty f\,dx\) both converge or both diverge.
Direct Comparison
\(0 \le a_n \le b_n\): if \(\sum b_n\) converges, so does \(\sum a_n\). If \(\sum a_n\) diverges, so does \(\sum b_n\).
Limit Comparison
\(\lim_{n\to\infty}\dfrac{a_n}{b_n} = L\) (0 < L < ∞): \(\sum a_n\) and \(\sum b_n\) have the same convergence behavior.
Ratio Test KEY for n! and a^n
\(L = \displaystyle\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|\)

\(L < 1\): converges absolutely
\(L > 1\) or \(\infty\): diverges
\(L = 1\): inconclusive
Root Test
\(L = \displaystyle\lim_{n\to\infty} \sqrt[n]{|a_n|}\)

\(L < 1\): converges
\(L > 1\): diverges
\(L = 1\): inconclusive
Alternating Series Test (Leibniz)
\(\displaystyle\sum (-1)^n b_n\) converges if: (1) \(b_n > 0\), (2) \(b_{n+1} \le b_n\) (decreasing), (3) \(\lim b_n = 0\).
Alternating Series Estimation Theorem AP EXAM KEY
\(|S - S_n| \le b_{n+1}\)
Error bounded by the first unused term. Error has same sign as first unused term.
Quick decision chart
ar^n or geometric-looking? → Geometric Series formula 1/n^p type? → p-Series Contains n! or a^n? → Ratio Test Similar to known convergent series → Comparison tests Alternates (−1)^n? → Alternating Series Test f(n) easily integrable? → Integral Test Contains n-th root throughout? → Root Test
Ratio Test on n!
\(\sum \frac{n!}{2^n}\) |a_{n+1}/a_n| = (n+1)!/2^{n+1} · 2^n/n! = (n+1)/2 → ∞ L > 1 → diverges
Limit Comparison example
\(\sum \frac{3n+5}{n^3 + 2}\) — behaves like 3n/n³ = 3/n² Compare with \(\sum 1/n^2\) (p-series, p=2>1, converges) lim (3n+5)/(n³+2) · n² = lim (3n³+5n²)/(n³+2) = 3 L = 3 ∈ (0,∞) → same behavior → converges ✓
Power Series
Power Series centered at \(x = a\) $$\sum_{n=0}^{\infty} c_n(x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots$$
Radius of Convergence
\(R = \displaystyle\lim_{n\to\infty}\left|\frac{c_n}{c_{n+1}}\right|\) (via Ratio Test)
Converges for \(|x - a| < R\)
Interval of Convergence
\((a-R,\; a+R)\) plus possibly endpoints.
Check endpoints separately!
Differentiating or integrating a power series term-by-term preserves the radius of convergence \(R\). Endpoints must be rechecked for the new series.
Taylor & Maclaurin Series
Taylor Series for \(f\) centered at \(x = a\) $$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n$$
Essential Maclaurin Series — Memorize All Six
\(e^x\) — converges for all \(x\)
\(e^x = \displaystyle\sum_{n=0}^{\infty}\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots\)
\(\sin x\) — converges for all \(x\)
\(\sin x = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{6} + \frac{x^5}{120} - \cdots\)
\(\cos x\) — converges for all \(x\)
\(\cos x = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \cdots\)
\(\frac{1}{1-x}\) — converges for \(|x| < 1\)
\(\dfrac{1}{1-x} = \displaystyle\sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots\)
\(\ln(1+x)\) — converges for \(-1 < x \le 1\)
\(\ln(1+x) = \displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n+1}x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots\)
\(\arctan x\) — converges for \(|x| \le 1\)
\(\arctan x = \displaystyle\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{2n+1} = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\)
Substitution strategy (most common AP technique)
Replace \(x\) with an expression in the known series formula. This is faster than computing derivatives.
Examples
e^{x²}: replace x with x² in e^x series = 1 + x² + x⁴/2! + x⁶/3! + ... sin(x³): replace x with x³ in sin x series = x³ − x⁹/6 + x¹⁵/120 − ... 1/(1+x²): replace x with −x² in 1/(1−x) series = 1 − x² + x⁴ − x⁶ + ... (this gives arctan series when integrated!)
Integrating series
\(\int \frac{\sin x}{x}\,dx\): use sin x series divided by x, then integrate term-by-term sin x/x = 1 − x²/6 + x⁴/120 − ... ∫ = x − x³/18 + x⁵/600 − ... + C
Finding specific coefficients
The coefficient of \((x-a)^n\) in the Taylor series is \(\dfrac{f^{(n)}(a)}{n!}\). If asked for the 3rd-degree term, compute \(f'''(a)/6\).
Lagrange Error Bound CRITICAL AP TOPIC
Lagrange Error Bound (Taylor Remainder)
If \(T_n(x)\) is the \(n\)th-degree Taylor polynomial for \(f\) centered at \(a\): $$|f(x) - T_n(x)| \le \frac{M \cdot |x - a|^{n+1}}{(n+1)!}$$ where \(M = \max|f^{(n+1)}|\) on the interval between \(a\) and \(x\).
Find the \((n+1)\)th derivative of \(f\).
Find its maximum absolute value \(M\) on the interval \([a, x]\).
Plug into \(|R_n| \le \dfrac{M|x-a|^{n+1}}{(n+1)!}\).
Full Lagrange example
Approximate e^{0.1} using the 3rd-degree Maclaurin polynomial. T₃(x) = 1 + x + x²/2 + x³/6 f(x) = e^x, f^{(4)}(x) = e^x M = max |e^x| on [0, 0.1] = e^{0.1} < e^1 < 3 (use M = 3 to be safe) |error| ≤ 3 · (0.1)⁴ / 4! = 3 · 0.0001 / 24 = 0.0000125
When to use alternating series estimate instead
For alternating series (sin, cos, arctan, ln(1+x)), the error is simply ≤ first unused term. This is simpler and always valid when the series satisfies AST conditions.
AP exam tip
The exam will often say "find a bound for the error" — use Lagrange for non-alternating Taylor series (like \(e^x\)), and the AST estimation for alternating ones. Both are fair game.
Telescoping Series
Telescoping Pattern
\(\displaystyle\sum_{n=1}^{\infty}(a_n - a_{n+1}) = a_1 - \lim_{n\to\infty} a_{n+1}\)
Use partial fractions to reveal telescoping. Example: \(\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}\) → sum \(= 1\).
