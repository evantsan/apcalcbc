Unit 1

Limits & Continuity

The foundation of calculus. Formal definitions, limit laws, special limits, continuity, and the key theorems that underpin everything that follows.

Informal & Formal Definition of a Limit

The limit of f(x) as x approaches c equals L means f(x) gets arbitrarily close to L as x gets close (but not equal) to c.

ε-δ Formal Definition
limx→c f(x) = L means: for every ε > 0, there exists δ > 0 such that
0 < |x − c| < δ ⟹ |f(x) − L| < ε
The limit does NOT care about the value of f(c) — only what happens near c.
Limit Laws
Sum / Difference
lim[f ± g] = lim f ± lim g
Constant Multiple
lim[c·f(x)] = c · lim f(x)
Product
lim[f·g] = lim f · lim g
Quotient
lim[f/g] = lim f / lim g (lim g ≠ 0)
Power
lim[f(x)]n = [lim f(x)]n
Root
lim √f(x) = √(lim f(x))
Special / Essential Limits
Trig Limit #1 KEY
limx→0 sin(x)/x = 1
Trig Limit #2 KEY
limx→0 (1−cos x)/x = 0
Natural Base
limn→∞ (1 + 1/n)n = e
General Form
limx→0 (1 + x)1/x = e
Exponential
limx→0 (ex−1)/x = 1
Logarithm
limx→0 ln(1+x)/x = 1
One-Sided Limits

limx→c f(x) exists if and only if both one-sided limits exist and are equal.

limx→c f(x) = L ⟺ limx→c⁻ f(x) = L AND limx→c⁺ f(x) = L
Limits at Infinity & Asymptotes
Horizontal Asymptotes
Rational Functions — Degree Comparison
deg(num) < deg(den): lim = 0
deg(num) = deg(den): lim = lead coeff ratio
deg(num) > deg(den): lim = ±∞ (no H.A.)
Exponential Growth Hierarchy
ln(x) ≪ xn ≪ ax ≪ x! ≪ xx
(as x→∞)
Vertical Asymptotes

x = c is a vertical asymptote if limx→c f(x) = ±∞. This happens when the denominator → 0 and the numerator ≠ 0 at x = c.

Squeeze Theorem
Squeeze Theorem
If g(x) ≤ f(x) ≤ h(x) near x = c, and
limx→c g(x) = limx→c h(x) = L,
then limx→c f(x) = L.

Classic use: limx→0 x²·sin(1/x) = 0 since |x²·sin(1/x)| ≤ x².
Continuity
Three Conditions for Continuity at x = c
1. f(c) is defined
2. limx→c f(x) exists
3. limx→c f(x) = f(c)

All three must hold. Fail any one → discontinuous.
Types of Discontinuities
Removable (Hole)
lim exists but ≠ f(c)
The limit exists; f(c) is either undefined or wrong value. "Fixable" by redefining f(c).
Jump
limc⁻ ≠ limc⁺
Left and right limits both exist but differ. Common in piecewise functions.
Infinite (Essential)
lim = ±∞
Vertical asymptote at x = c. Not removable.
Intermediate Value Theorem (IVT)
Intermediate Value Theorem
If f is continuous on [a, b] and M is any value between f(a) and f(b), then there exists at least one c ∈ (a, b) such that f(c) = M.

Key use: Proving a root/zero exists — if f(a) < 0 and f(b) > 0 (or vice versa), a root must exist in (a, b).
IVT guarantees existence, not uniqueness. Always verify continuity first!
Unit 2

Basic Differentiation

Definition of the derivative, all core differentiation rules, and the complete table of derivatives for algebraic, trigonometric, exponential, and logarithmic functions.

Definition of the Derivative
Limit Definition (at a point)
f'(a) = limh→0 [f(a+h) − f(a)] / h
Alternate Form
f'(a) = limx→a [f(x) − f(a)] / (x−a)

The derivative f'(x) gives the instantaneous rate of change of f at x, and the slope of the tangent line to f at (x, f(x)).

Differentiability ⟹ Continuity
If f is differentiable at x = c, then f is continuous at x = c.
The converse is FALSE — continuous does not mean differentiable.
Fails at: corners, cusps, vertical tangents, jumps.
Core Differentiation Rules
Constant Rule
d/dx[c] = 0
Power Rule MOST USED
d/dx[xn] = nxn−1
Constant Multiple
d/dx[c·f] = c·f'
Sum / Difference
d/dx[f ± g] = f' ± g'
Product & Quotient Rules
Product Rule KEY
d/dx[u·v] = u'v + uv'
"First times derivative of second, plus second times derivative of first"
Quotient Rule KEY
d/dx[u/v] = (u'v − uv') / v²
"Low d-High minus High d-Low, over Low squared"
Derivatives of Trigonometric Functions
Function f(x)Derivative f'(x)Note
sin(x)cos(x)
cos(x)−sin(x)
tan(x)sec²(x)
cot(x)−csc²(x)
sec(x)sec(x)·tan(x)
csc(x)−csc(x)·cot(x)
Derivatives of co-functions (cos, cot, csc) all have a negative sign. Easy pattern to remember!
Exponential & Logarithmic Derivatives
Natural Exponential
d/dx[ex] = ex
The only function equal to its own derivative.
General Exponential
d/dx[ax] = ax·ln(a)
Natural Log
d/dx[ln(x)] = 1/x (x > 0)
General Log
d/dx[loga(x)] = 1/(x·ln a)
|x| version
d/dx[ln|x|] = 1/x (x ≠ 0)
Tangent Lines & Normal Lines
Tangent Line at (a, f(a))
y − f(a) = f'(a)(x − a)
Normal Line at (a, f(a))
y − f(a) = −1/f'(a)(x − a)
Normal line is perpendicular to tangent (slopes are negative reciprocals)
Higher-Order Derivatives
Notation
f', f'', f''', f(4), ..., f(n)
dy/dx, d²y/dx², d³y/dx³
Common Higher Derivatives
dn/dxn[sin x] cycles:
sin, cos, −sin, −cos, sin...
Unit 3

Advanced Differentiation

Chain rule, implicit differentiation, inverse function derivatives, and all inverse trigonometric derivatives.

Chain Rule
Chain Rule — Composite Functions d/dx[f(g(x))] = f'(g(x)) · g'(x)
Leibniz Notation
dy/dx = dy/du · du/dx
Chain + Power
d/dx[un] = n·un−1·u'
Chain + Trig
d/dx[sin(u)] = cos(u)·u'
Chain + Exp
d/dx[eu] = eu·u'
Chain + Log
d/dx[ln(u)] = u'/u
General Power (au)
d/dx[au] = au·ln(a)·u'
With nested chains, "peel the onion" — differentiate the outermost function first, then multiply by derivative of the inner function.
Implicit Differentiation

Used when y cannot be solved explicitly in terms of x, or when it's easier not to. Differentiate both sides with respect to x, treating y as a function of x and applying the chain rule.

Differentiate every term with respect to x. Terms with y get an extra factor of dy/dx (chain rule).
Collect all dy/dx terms on one side.
Factor out dy/dx and solve.
Key Rule
d/dx[yn] = n·yn−1 · (dy/dx)
Example: d/dx[x² + y²] = 2x + 2y·(dy/dx). If this equals 0, then dy/dx = −x/y.
Derivatives of Inverse Functions
Inverse Function Derivative Theorem
If f and f⁻¹ are inverse functions and f is differentiable at f⁻¹(x), then:

(f⁻¹)'(x) = 1 / f'(f⁻¹(x))

In other words: dx/dy = 1 / (dy/dx)
On the AP exam: "If f(3) = 7 and f'(3) = 4, find (f⁻¹)'(7)." Answer: 1/f'(3) = 1/4.
Derivatives of Inverse Trigonometric Functions
FunctionDerivativeDomain
arcsin(x)1 / √(1−x²)|x| < 1
arccos(x)−1 / √(1−x²)|x| < 1
arctan(x)1 / (1+x²)all x
arccot(x)−1 / (1+x²)all x
arcsec(x)1 / (|x|√(x²−1))|x| > 1
arccsc(x)−1 / (|x|√(x²−1))|x| > 1

With chain rule: d/dx[arctan(u)] = u' / (1 + u²). Apply this pattern to all inverse trig formulas.

Logarithmic Differentiation

Use when differentiating complex products/quotients or variable-base exponentials like xsin x.

Take ln of both sides: ln y = ln[f(x)]
Simplify using log properties (ln(ab) = ln a + ln b, etc.)
Differentiate both sides implicitly: (1/y)·y' = [simplified expression]
Solve for y' and substitute back y = f(x)
Variable Exponent: y = xx
ln y = x·ln x → y'/y = ln x + 1
y' = xx(ln x + 1)
Unit 4

Contextual Applications of Differentiation

Motion problems, related rates, linearization, and L'Hôpital's Rule for indeterminate forms.

Motion Along a Line
Position
s(t) or x(t)
Velocity
v(t) = s'(t)
Acceleration
a(t) = v'(t) = s''(t)
Speed
|v(t)| (always ≥ 0)
Speeding Up
v and a have same sign
Slowing Down
v and a have opposite signs
Particle changes direction when v(t) = 0 AND v changes sign. Always check the sign change!
Related Rates

Variables change with respect to time. Use implicit differentiation with respect to t.

Draw a diagram and label all variables.
Write an equation relating the variables (geometric formula, Pythagorean theorem, similar triangles, etc.).
Differentiate both sides with respect to t (implicit differentiation).
Substitute the known values (NOT before differentiating!) and solve for the unknown rate.
Common Related Rate Setups
Pythagorean (Ladder Problems)
a² + b² = c²
2a(da/dt) + 2b(db/dt) = 2c(dc/dt)
Circle Area
A = πr² →
dA/dt = 2πr · (dr/dt)
Sphere Volume
V = (4/3)πr³ →
dV/dt = 4πr² · (dr/dt)
Cone Volume
V = (1/3)πr²h →
use similar triangles to eliminate one variable
Linear Approximation (Linearization)
Linearization of f at x = a L(x) = f(a) + f'(a)(x − a)

L(x) is the tangent line at x = a used to approximate f(x) for x near a.

Differential
dy = f'(x)·dx ≈ Δy = f(x+Δx) − f(x)
Used to estimate small changes. If dx is small, dy ≈ the actual change in y.
L'Hôpital's Rule BC KEY
L'Hôpital's Rule
If lim f(x)/g(x) gives the indeterminate form 0/0 or ∞/∞, then:

lim f(x)/g(x) = lim f'(x)/g'(x)

provided the limit on the right exists (or is ±∞).
Indeterminate Forms → How to Handle
FormStrategy
0/0, ∞/∞Apply L'Hôpital directly
0·∞Rewrite as 0/(1/∞) or ∞/(1/0), then L'Hôpital
∞ − ∞Combine fractions or rationalize
1∞, 00, ∞0Take ln, then apply L'Hôpital to the ln form
L'Hôpital does NOT apply if the limit is NOT indeterminate. Verify the form first!
Unit 5

Analytical Applications of Differentiation

MVT, EVT, Rolle's Theorem, finding extrema, concavity analysis, curve sketching, and optimization.

Key Theorems
Extreme Value Theorem (EVT)
If f is continuous on [a, b], then f attains both an absolute maximum and an absolute minimum on [a, b].
Rolle's Theorem
If f is continuous on [a,b], differentiable on (a,b), and f(a) = f(b), then there exists at least one c ∈ (a, b) such that f'(c) = 0.
Mean Value Theorem (MVT)
If f is continuous on [a,b] and differentiable on (a,b), then there exists at least one c ∈ (a, b) such that:

f'(c) = [f(b) − f(a)] / (b − a)

The instantaneous rate of change equals the average rate of change somewhere.
MVT is Rolle's Theorem without the f(a) = f(b) requirement. Rolle's is a special case of MVT.
Critical Points & Extrema
Critical Point Definition
f'(c) = 0 OR f'(c) does not exist (DNE)
Critical points are candidates for local extrema. But not every critical point is an extremum!
Finding Absolute Extrema on [a, b]
Find all critical points in (a, b).
Evaluate f at each critical point AND at the endpoints a and b.
The largest value is the absolute max; the smallest is the absolute min.
First & Second Derivative Tests
First Derivative Test
f' changes + → −: local MAX
f' changes − → +: local MIN
f' no sign change: no extremum
Second Derivative Test
f'(c) = 0 AND f''(c) < 0: local MAX
f'(c) = 0 AND f''(c) > 0: local MIN
f''(c) = 0: inconclusive (use 1st test)
Concavity & Inflection Points
Concave Up
f''(x) > 0 on interval
tangent lines lie BELOW the curve
Concave Down
f''(x) < 0 on interval
tangent lines lie ABOVE the curve
Inflection Point
A point where concavity changes (from up to down or vice versa). Find candidates where f''(x) = 0 or DNE, then verify that f'' changes sign. Just f''(c) = 0 is NOT enough!
Curve Sketching Checklist
Domain & Intercepts: Where is f defined? Find x- and y-intercepts.
Symmetry: Even (symmetric about y-axis), odd (symmetric about origin)?
Asymptotes: Horizontal (limits at ±∞), vertical (where denominator = 0).
Increasing/Decreasing: Find f', solve f' = 0, make sign chart.
Local Extrema: Apply first or second derivative test at critical points.
Concavity & Inflection: Find f'', solve f'' = 0, make sign chart.
Sketch: Plot key points and connect with proper behavior.
Optimization
Identify the quantity to maximize or minimize (the objective function).
Write a constraint equation relating the variables.
Use the constraint to reduce the objective to one variable.
Find the derivative, set equal to zero, and solve for critical points.
Verify it's a max or min using first/second derivative test or endpoints.
Answer the question in context (include units!).
Common optimization setups: max area with fixed perimeter, min material for fixed volume, max revenue/profit, closest point on curve to a given point.
Unit 6

Integration & Accumulation of Change

Riemann sums, the Fundamental Theorem of Calculus, antiderivatives, and all integration techniques: u-substitution, integration by parts, partial fractions, and improper integrals.

Riemann Sums
Subinterval Width
Δx = (b − a) / n
Left Riemann Sum
Ln = Δx · Σi=0n-1 f(xi)
Right Riemann Sum
Rn = Δx · Σi=1n f(xi)
Midpoint Sum
Mn = Δx · Σ f(midpoints)
Trapezoidal Rule KEY
Tn = (Δx/2)[f(x0) + 2f(x1) + 2f(x2) + ... + 2f(xn-1) + f(xn)]
Average of Left and Right sums: Tn = (Ln + Rn)/2. Overestimates for concave up, underestimates for concave down.
Overestimate/Underestimate summary:
Increasing f: Left underestimates, Right overestimates.
Decreasing f: Left overestimates, Right underestimates.
Concave up: Trapezoidal overestimates, Midpoint underestimates.
Concave down: Trapezoidal underestimates, Midpoint overestimates.
Fundamental Theorem of Calculus
FTC Part 1 — Evaluation Theorem
If F is an antiderivative of f (F' = f), then:

∫ab f(x) dx = F(b) − F(a)

Also written as [F(x)]ab
FTC Part 2 — Antiderivative Theorem
If f is continuous on [a, b], then the function
g(x) = ∫ax f(t) dt
is continuous on [a, b], differentiable on (a, b), and g'(x) = f(x).

With chain rule: d/dx[∫ag(x) f(t) dt] = f(g(x)) · g'(x)

∫(f±g)dx = ∫f dx ± ∫g dx
Additive Interval
∫ac f dx = ∫ab f dx + ∫bc f dx
Comparison
f ≥ g on [a,b] ⟹ ∫f ≥ ∫g

U-Substitution

Reverse of the chain rule. Used when an integral contains a composite function.

Identify u = g(x) (usually the "inside" function).
Find du = g'(x) dx. Solve for dx if needed.
Rewrite the integral entirely in terms of u.
Integrate with respect to u.
Back-substitute u = g(x). (For definite integrals, change the limits to u-values instead.)
Integration by Parts BC
Integration by Parts ∫ u dv = uv − ∫ v du
LIATE — Choosing u (pick first from this list)
Logarithms · Inverse trig · Algebraic · Trig · Exponential
The leftmost category should be u; the rightmost should be dv.
When IBP cycles back to the original integral (like ∫exsin x dx), call the original integral I and solve for I algebraically.
Partial Fraction Decomposition BC

Decomposes a rational function into simpler fractions before integrating.

Distinct Linear Factors
P(x)/[(x−a)(x−b)] =
A/(x−a) + B/(x−b)
Repeated Linear Factor
P(x)/(x−a)² =
A/(x−a) + B/(x−a)²
Irreducible Quadratic
P(x)/[(x−a)(x²+bx+c)] =
A/(x−a) + (Bx+C)/(x²+bx+c)
The degree of the numerator must be less than the denominator. If not, do polynomial long division first.
Improper Integrals BC
Infinite Upper Bound
∫a∞ f dx = limt→∞ ∫at f dx
Discontinuity in [a,b]
∫ab f dx = limt→c⁻ ∫at f dx

If the limit exists and is finite, the integral converges. Otherwise it diverges.

p-integral test
∫1∞ 1/xp dx: converges if p > 1, diverges if p ≤ 1
∫01 1/xp dx: converges if p < 1, diverges if p ≥ 1
Unit 7

Differential Equations

Slope fields, separable DEs, Euler's method, and the logistic differential equation.

Slope Fields

A slope field represents a DE dy/dx = F(x, y) by drawing short line segments at each point (x, y) with slope F(x, y). Solutions to the DE are curves that follow these segments.

Along a horizontal line y = k, if F(x, y) depends only on y, all slopes are equal → horizontal "stripes" in the slope field.
Separable Differential Equations
Separate variables: get all y-terms (including dy) on one side, all x-terms (including dx) on the other.
Integrate both sides.
Solve for y (if possible).
Apply initial condition to find the constant C.
Exponential Growth/Decay
dy/dt = ky → y = Cekt
k > 0: growth. k < 0: decay. C = y(0) = initial value.
Half-life / Doubling Time
Half-life: t½ = ln(2)/|k|
Doubling: td = ln(2)/k
Euler's Method BC
Euler's Method Algorithm
Given dy/dx = F(x, y), starting point (x0, y0), and step size h:

xn+1 = xn + h
yn+1 = yn + h · F(xn, yn)

Repeat until the desired x-value is reached.
Euler's method is an approximation. Smaller step size h → more accurate but more steps. The approximation follows tangent line segments.
Logistic Differential Equation BC
Logistic Model dP/dt = kP(1 − P/M)

Where M = carrying capacity (maximum population), k = growth rate constant, P = population.

Logistic Solution
P(t) = M / (1 + Ae−kt)
where A = (M − P0)/P0
Key Properties
Max growth rate at P = M/2
limt→∞ P(t) = M
Inflection point at P = M/2
Logistic Behavior Summary
• P < M/2: dP/dt increasing → population accelerating
• P = M/2: maximum rate of change (inflection point of P vs t)
• P > M/2: dP/dt decreasing → population decelerating
• P → M: growth rate approaches 0, population approaches carrying capacity
Unit 8

Applications of Integration

Area between curves, volumes of revolution (disk, washer, shell), arc length, and average value.

Area Between Curves
Vertical Slices (in x)
A = ∫ab [top − bottom] dx
= ∫[f(x) − g(x)] dx
Horizontal Slices (in y)
A = ∫cd [right − left] dy
= ∫[f(y) − g(y)] dy
Find intersection points (set f = g and solve).
Determine which function is on top (or right) in the interval.
Integrate (top − bottom) or (right − left).
If the functions cross, split the integral at each crossing point.
Volumes of Revolution
Disk Method (solid, no hole)
Rotation about x-axis
V = π ∫ab [f(x)]² dx
Rotation about y-axis
V = π ∫cd [f(y)]² dy
Washer Method (hollow — region between two curves)
Rotation about x-axis
V = π ∫ab ([R(x)]² − [r(x)]²) dx
R = outer radius, r = inner radius
Rotation about y = k
R(x) = |top function − k|
r(x) = |bottom function − k|
Shell Method BC
Rotation about y-axis
V = 2π ∫ab x · f(x) dx
Radius = x, height = f(x)
Rotation about x-axis
V = 2π ∫cd y · f(y) dy
Use disk/washer when slices are perpendicular to the axis of rotation. Use shells when slices are parallel to the axis. Often shells are easier when rotating about y but the function is given in terms of x.
Arc Length BC
Arc Length (Cartesian)
L = ∫ab √(1 + [f'(x)]²) dx
Arc Length (in y)
L = ∫cd √(1 + [g'(y)]²) dy
Average Value of a Function
Average Value favg = 1/(b−a) · ∫ab f(x) dx
Mean Value Theorem for Integrals
If f is continuous on [a, b], there exists c ∈ [a, b] such that
f(c) = favg = (1/(b−a)) ∫ab f(x) dx
The function attains its average value at some point in the interval.
Accumulation & Net Change
Net Change Theorem
∫ab F'(x) dx = F(b) − F(a) (net change in F)
Total distance = ∫|v(t)| dt | Displacement = ∫v(t) dt
Unit 9 — BC Only

Parametric, Polar & Vectors

Calculus with parametric curves, polar coordinates, and vector-valued functions. Derivatives, arc length, area, and motion in the plane.

Parametric Equations

A curve is defined by x = f(t) and y = g(t) for t in some interval. The parameter t often represents time.

First Derivative (slope)
dy/dx = (dy/dt) / (dx/dt) = ẏ/ẋ
Horizontal tangent: dy/dt = 0 (and dx/dt ≠ 0). Vertical tangent: dx/dt = 0 (and dy/dt ≠ 0).
Second Derivative
d²y/dx² = d(dy/dx)/dt ÷ (dx/dt)
= [d/dt(dy/dx)] / (dx/dt)
Arc Length
L = ∫ab √((dx/dt)² + (dy/dt)²) dt
Speed at time t
speed = √((dx/dt)² + (dy/dt)²)
Polar Coordinates

Points expressed as (r, θ) where r = distance from origin, θ = angle from positive x-axis.

Conversion to Cartesian
x = r cos θ
y = r sin θ
r² = x² + y²
Slope of Polar Curve
dy/dx = (r'sinθ + rcosθ) / (r'cosθ − rsinθ)
Area in Polar Coordinates
Area enclosed by polar curve r = f(θ) A = ½ ∫αβ r² dθ = ½ ∫αβ [f(θ)]² dθ
Area between two polar curves
A = ½ ∫αβ ([R(θ)]² − [r(θ)]²) dθ
R = outer curve, r = inner curve. Find α, β by setting R = r.
Arc Length in Polar
Polar Arc Length
L = ∫αβ √(r² + (dr/dθ)²) dθ
Common Polar Curves to Know

Vector-Valued Functions

A vector-valued function describes motion in the plane: r(t) = ⟨x(t), y(t)⟩.

Position Vector
r(t) = ⟨x(t), y(t)⟩
Velocity Vector
v(t) = r'(t) = ⟨x'(t), y'(t)⟩
Acceleration Vector
a(t) = v'(t) = ⟨x''(t), y''(t)⟩
Speed
|v(t)| = √(x'² + y'²)
Distance traveled
∫ab |v(t)| dt (arc length)
Displacement
∫ab v(t) dt = ⟨Δx, Δy⟩
Position from v(t)
r(t) = r(t0) + ∫t₀t v(s) ds
Unit 10 — BC Only

Infinite Sequences & Series

The most BC-heavy unit. Sequences, all convergence tests, power series, Taylor and Maclaurin series, and the Lagrange error bound.

Sequences

A sequence {an} converges if limn→∞ an = L (a finite number). Otherwise it diverges.

Geometric Sequence
an = a·rn−1
Converges iff |r| < 1
Key Growth Rates (n→∞)

Series — Convergence Tests
nth Term Divergence Test
If limn→∞ an ≠ 0, then Σan diverges.
⚠ If lim an = 0, the test is INCONCLUSIVE — the series may converge or diverge.
Geometric Series MOST IMPORTANT
Σn=0∞ a·rn = a/(1−r) if |r| < 1; diverges if |r| ≥ 1
p-Series MUST KNOW
Σ 1/np: converges if p > 1, diverges if p ≤ 1
Harmonic series Σ1/n diverges (p=1)
Integral Test
Integral Test
If f is continuous, positive, and decreasing on [1,∞), and an = f(n), then
Σan and ∫1∞ f(x) dx both converge or both diverge.
Comparison Tests
Direct Comparison Test
0 ≤ an ≤ bn:
Σbn converges ⟹ Σan converges
Σan diverges ⟹ Σbn diverges
Limit Comparison Test
limn→∞ an/bn = L (0 < L < ∞)
Then Σan and Σbn both converge or both diverge
Ratio & Root Tests
Ratio Test KEY for factorials/exponentials
L = limn→∞ |an+1/an|

L < 1: converges absolutely
L > 1 or ∞: diverges
L = 1: inconclusive
Root Test
L = limn→∞ n√|an| = lim |an|1/n

L < 1: converges absolutely
L > 1: diverges
L = 1: inconclusive
Alternating Series
Alternating Series Test (Leibniz Test)
Σ(−1)nbn converges if: (1) bn > 0, (2) bn+1 ≤ bn (decreasing), and (3) lim bn = 0.
Alternating Series Estimation Theorem KEY
|error| = |S − Sn| ≤ bn+1 (the first omitted term)
The error is bounded by the first unused term (and has the same sign as that term).
Absolute Convergence
Σ|an| converges ⟹ Σan converges
Absolute convergence implies convergence, not vice versa.
Conditional Convergence
Σan converges but Σ|an| diverges
Example: Σ(−1)n/n converges (conditionally) by AST.

Power Series
Power Series centered at x = a Σn=0∞ cn(x − a)n = c0 + c1(x−a) + c2(x−a)² + ...
Radius of Convergence R
Use Ratio Test: R = lim |cn/cn+1|
or R = 1 / lim |cn|1/n
Series converges for |x − a| < R, diverges for |x − a| > R. Check endpoints separately!
Interval of Convergence
I = (a−R, a+R) plus possibly endpoints
Check x = a±R with original tests

Same radius R. Differentiate/integrate term by term.

Taylor & Maclaurin Series
Taylor Series for f centered at x = a f(x) = Σn=0∞ f(n)(a) / n! · (x − a)n

A Maclaurin series is a Taylor series centered at a = 0.

Essential Maclaurin Series — MEMORIZE ALL OF THESE
ex — Interval: (−∞, ∞)
ex = Σ xn/n! = 1 + x + x²/2! + x³/3! + ...
sin(x) — Interval: (−∞, ∞)
sin x = Σ (−1)nx2n+1/(2n+1)!
= x − x³/6 + x⁵/120 − ...
cos(x) — Interval: (−∞, ∞)
cos x = Σ (−1)nx2n/(2n)!
= 1 − x²/2 + x⁴/24 − ...
1/(1−x) — Interval: (−1, 1)
1/(1−x) = Σ xn = 1 + x + x² + x³ + ...
ln(1+x) — Interval: (−1, 1]
ln(1+x) = Σ (−1)n+1xn/n
= x − x²/2 + x³/3 − ...
arctan(x) — Interval: [−1, 1]
arctan x = Σ (−1)nx2n+1/(2n+1)
= x − x³/3 + x⁵/5 − ...
To find series for ex², substitute x² for x in the ex series. To integrate sin(x²), substitute x² into sin(x) series and integrate term by term. Substitution is your best friend here!
Lagrange Error Bound (Taylor Remainder)
Lagrange Error Bound KEY AP TOPIC
If Tn(x) is the nth-degree Taylor polynomial for f centered at a, the error satisfies:

|f(x) − Tn(x)| ≤ M · |x − a|n+1 / (n+1)!

where M is the maximum value of |f(n+1)| on the interval between a and x.
Find the (n+1)th derivative of f.
Find its maximum absolute value M on the interval [a, x] (or [x, a]).
Compute: |error| ≤ M · |x − a|n+1 / (n+1)!
For alternating series, the error ≤ the first omitted term (simpler method — use when the series is alternating). Use Lagrange when the series is NOT alternating.
Telescoping Series
Telescoping Series
Σ (an − an+1) = a1 − limn→∞ an+1
Partial fractions often reveal telescoping. Example: 1/[n(n+1)] = 1/n − 1/(n+1) → sum = 1.
